Public palette references for Creative Whiteboard

The original six presets are retained unchanged. Eleven additional UI presets map named published palette roles to the existing workbench. Text, links and focus colors still use the existing contrast adjustment; this is a whiteboard adaptation, not an official port or endorsement. Existing authored note colors are never replaced. No network request is needed to select a palette.
