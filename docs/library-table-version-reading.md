# 看清多列表格，再选择保留的版本

内容库编辑表格时，如果同一张表有后来修改，仍沿原入口比较“库中版本”和“我的编辑”。两份表格与展开的“编辑前的版本”都为每列保留阅读宽度。列多时，在各自表格内部横向查看最后几列和格内资料摘要，再明确选择保留哪份并保存。

这项调整沿用普通表格编辑区域每列160像素、整表至少320像素的阅读宽度。两列的小表保持原有宽度，更多列不会挤成逐字竖排；横向区域可聚焦并使用方向键。整页布局、表格原始列宽数据、行列对应、格内附件及选择/保存规则保持原样。

本机合成核对覆盖1360与320像素窗口中的两列/十二列表格，核对文字与资料、区域内横向查看最后一列、键盘查看不自动选择、展开编辑前版本，以及明确保存完整表格和独立后来说明/尺寸。原表格编辑任务保持原样执行，继续覆盖后来版本使旧选择失效、保留库中版本、原稿输入、失败重试、取消和观察到的所属范围保护。

新任务登记原 `test:browser` / Check 与 `LIBRARY_TABLE_VERSION_READING_PROOF` 证据留存。当前阶段为本机源码及合成核对；准确当前提交CI、服务器QA、网站更新、私人安装、真实托管账号、实体设备、输入法及作者实际使用仍待对应阶段验证。合成窗口的阅读尺寸不代表实体设备或作者体验结论。
