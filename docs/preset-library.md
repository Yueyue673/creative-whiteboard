# 把自己的预设备份收进内容库

在“外观与操作 → 我的预设 → 预设备份与导入”中填写备份名称，点“收进内容库”。它把已经保存的预设作为一份 JSON 文件加入当前内容库根目录，沿用内容库的读取权限；当前尚未保存的调整需先存为预设。原“导出我的预设”和“选择预设文件”仍可使用。

两边能访问同一内容库时，可以在另一浏览器点“从内容库取回”，再明确选择一份备份。它仍先显示原导入预览：勾选要加入的预设，确认加入后，再从“我的预设”明确选择应用。已有同名项、当前外观与其他预设保留；取消和撤销导入沿原流程。

这是一次明确收存和取回。修改本机预设后，库里的旧备份不会自动跟着改变；取回也不会自动同步或应用外观。文件只包含已保存的预设名称、外观和操作参数，不含原预设编号、白板正文或素材。

列表识别本功能保存的 .appearance-presets.json 文件及原导出的默认文件名，只读取本人点击的文件。备份最多 256 KiB，目录读取最多 8 MiB / 12000 项，列表最多显示 80 份；其他文件可继续从内容库下载后用原文件入口导入。读取前核对当前条目，改名、移动、删除或原登录范围变化后需重新核对。设备字体仍由各自系统提供。

收存请求中断时，服务器可能已经完成写入：先在内容库核对，再决定是否重试。关闭设置不会删除已经收存的备份，旧回执也不会改写后来打开的设置页。

## 验证范围

本机隔离的 1360px / 320px 任务使用两份独立浏览器资料和真实临时服务：库中备份与原文件导出 JSON 一致，省去中间手动下载、搬运和上传；原预览、取消、撤销、明确应用与两边写作现场保留，续写、原生撤销重做和保存新页读回准确。另核对失败重试、目录变化、大小限制、改选本地文件、关闭后的迟到回执，以及真实服务已收存后的回执中断。
