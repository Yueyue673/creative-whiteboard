# 只改一个已存外观的名称

**独立候选，尚未合入默认版本。** 下述入口已在候选源码中实现并通过本机合成核验；默认下载、网站和已有私人安装未随本切片更新。

在“外观与操作 → 我的预设”找到要处理的一条，点“改名”。填写新名称，点“保存名称”或按 Enter。它只改这条记录的名称；无需先应用该预设，也不会把当前设置存回它。已存配色、界面与操作偏好、记录编号和顺序、其他预设及当前工作台保留，便签与表格的内容和颜色也不会被这次改名覆盖。

“取消改名”或在名称框中按 Esc，会退出这次改名。改好后可点“撤销改名”，当前正在看的外观保留。未改名称就保存，不会取消上次实际改名的撤销。满24条时也可以改名，无需先移除一条。

名称输入独立于预设列表，调整当前颜色时仍保留。名称为空、与另一条重名、浏览器未能保存，或那条记录已有后续变化时，不覆盖已存数据，输入仍在。旧窗口留下的按钮或旧撤销不会覆盖后来修改。所有操作只限当前浏览器，不承诺多窗口事务或账号同步。

内容库里已收存的预设备份是独立文件，不会随本机改名自动变化。需要带走新名称时，再使用原有导出或收存入口。

## 核验范围

1360和320像素的独立合成白板中，使用原生设置、按钮及键盘操作核对：只改目标名称、原始记录额外字段、当前外观、混合便签和表格、输入身份与反向选区、取消、重名与空名、颜色刷新中的名称草稿、撤销、满24条、旧窗口按钮及刷新读回。保存失败和后续记录变化由明确标记的一次性浏览器资料模拟；不代表实际设备或真实多窗口并发验收。

原预设更新、原外观及设置返回写作任务也沿受影响路径核验。当前源码的准确 CI、公开上传、服务器QA、部署和私人安装仍待验证；实体设备、输入法、读屏及作者长期使用未据此宣称通过。
