# 暂时收起长文工具，接着写

展开长文后，原工具默认继续显示。想给纸面留出更多空间时，点“收起工具”；需要插入、取用、字体或其他原操作时，点“展开工具”即可。查找、来源与备注、返回白板仍在原标题栏。

收起只改变当前展开实例的显示，不改正文或保存偏好，也不自动替作者隐藏工具。原输入框、选区和阅读位置保留。收起时关闭原工具菜单，原Esc退出保持；重新打开长文默认显示工具。

给定320×660窗口中，写作区由约390像素增至约485像素，多出约96像素；1360×660的给定窗口增益为14像素。默认显示工具时，新增动作没有增加给定宽窄窗口的工具栏高度。此处是布局对照，不是真人写作速度测量。
