# 重试未添加文件

选择多个文件放入白板后，原位置会显示成功和失败的数量。点“重试未添加文件”，会重新处理这次选择中尚未放入的文件；已放好的内容不再发送、不再添加。

重试仍走原来的文件读取、上传和放入流程，保留格式与原文件。重试成功的内容避开已有纸张，保持当前视图和后来继续写的输入；它是单独一次撤销，撤销后先前成功的内容仍在。再次失败时，提示只保留这次尚未添加的文件。

只有明确点击才重试。原选择的文件仅留在当前失败提示的内存中，关闭提示即释放，不写入浏览器存储。刷新页面或重开窗口后需要重新选择。账号、工作区、权限、白板或内容库位置改变，以及保存尚有错误时，旧入口会要求重新选择，不向新位置发送文件。重试期间账号范围改变，会阻止后续文件上传和整批放入；已收到的文件可能仍留在原内容库中，不自动删除。

整个批次因容量或提交阶段失败时，不提供这个按文件重试入口。它也不取代内容库直接上传的现有流程。已经放入的文件不会重复发送；某个未放入的文件若上传已被服务器收到、后续确认失败，重试仍可能再次发送该文件，由原上传流程核对其内容身份。

## 找回原提示，再返回写作

等待文件时移开了画布，可在角落提示中点“回到未添加位置”，查看原来的失败提示。它只改变查看位置，不上传、重试、移动纸张或添加撤销记录。要重新处理文件，仍需点原提示中的“重试未添加文件”。

“返回刚才位置”恢复这次定位前的视图，保留当前输入与后来写的文字。关闭这条返回提示，只结束本次返回入口；原失败提示及其重试仍在。关闭实际的失败提示，则沿原流程释放未添加文件的临时选择。账号、工作区、白板或权限有变化时，旧定位和返回入口不再执行，不切换到其他白板，也不会自动拉回画面。

## 本机核验范围

隔离合成白板以原生文件选择和按钮操作覆盖 1360、320 像素视口：部分成功、全部逐文件失败、连续失败后再试、重复点击、关闭提示、保存读回、原文件字节、独立撤销/重做、等待中继续写作，以及账号范围变化。另用明确标记的模型/范围输入检查容量和旧入口归属。

没有改写页面或模块来代替功能。原批量导入的部分失败和编辑连续性任务沿受影响路径核验。新任务注册于原 Check 流程；当前提交尚未公开上传、运行准确 CI、服务器 QA、部署或私人安装。真实账号、实体设备、输入法及作者实际体验未据此宣称通过。

离屏定位另以原生平移、继续写作、按钮及键盘操作检查 1360、320 像素视口；范围变化仅使用明确标记的合成输入。定位和返回的请求计数、原视图、输入身份、选区、后来文字及保存读回分别核对。当前提交的准确 CI 与上线状态仍待验证。
