# 按创作任务查看近期候选

先选想完成的一件事，再进入对应操作说明。下面汇集截至2026年10月28日的八项本机源码候选，补上它们在版本任务导航中缺少的入口；默认下载与开发版入口见[版本与进度](status.md)。

| 想继续做什么 | 操作说明 | 主要适用范围 |
| --- | --- | --- |
| 找回一份库中原件已经用在哪些白板 | [查看用过的白板副本](library-copy-locations.md) | 按原件记录辨认副本和位置，沿原路径返回原稿；其他窗口尚未保存的变化可能不显示 |
| 写当前记录时，直接看库中便签原件 | [库中原件只读对照](library-writing-reference.md) | 普通纯文字便签，对照组合根层的同类便签；不创建临时副本或永久引用 |
| 编辑相似图片时看清当前对象 | [图片编辑窗口中的名称](image-workspace-context.md) | 显示当前图片对象自己的标题；长名最多两行，原裁剪和标注操作保留 |
| 窄窗里看着单张图片继续写 | [图片资料与写作同时看](image-writing-reference.md) | 已加载且没有其他文字、标签或混合材料的单图资料便签；高度不足时沿原资料方式 |
| 从组合中取用图片前，确认当前画面 | [按需查看组内图片](library-image-pieces.md) | 可查看当前裁剪和标注；看清后仍用原复选框取用，展开本身不选择 |
| 从单表或组合中取用表格前，先读格子 | [只读查看表格内容](library-table-pieces.md) | 阅读文字、格内记录和素材名称；超过预览范围时保留原取用路径 |
| 在关联列表中区分同名的格内内容 | [辨认表格与行列位置](link-location-choice.md) | 显示当前读到的表格、行列和嵌套路径；原引用编号及名称搜索规则保留 |
| 在一组材料的空白处开始一张新便签 | [按落点开始写](group-writing-point.md) | 足够大的分组空白处右键“在这里写便签”；宽窗行内写，窄窗展开后返回原白板 |
