# 在格中核对库里的便签原件

展开普通表格编辑，点中格里的复用便签，在原“更多”工具中选“查看库中原件”。原件使用现有的只读资料查看器，返回后继续在原格子的输入框中写，不必先另取一份副本到画布。

入口只针对有明确库来源的普通文字便签，跟随当前所选内容，不会给每个格子常驻一排按钮。原来的“取出副本”和“移除”顺序保留。自己新写且没有来源的内容、文件、图片和绘图继续沿原方式操作；长文中的原件入口也保持原方式。

同名资料和同名便签按记录中的资源编号与原件位置核对，不靠标题猜测。原整张表格复用后，只有确实存在于原资源中的格内便签才可继承该整表的来源。阅读不新增画布副本，不写回内容库，不给原稿增加阅读造成的撤销记录；读不到或无法唯一对应时，保留原稿并提示从内容库查看。

键盘可以在原“更多”工具中选择这个入口。返回复用现有查看器的方式：宽窗点资料旁的返回，窄窗点顶部“返回记录”。原输入框、当前选区和滚动位置保留；来源、所选内容、行列身份或所属范围变化时，不把旧结果用到另一份内容上。

## 验证范围

1360与320宽窗口的合成完整任务通过：两个同名资源含同名原件，分别从所选格打开准确原话，返回同一字段和反向选区并继续输入、原生撤销；核对新写无来源的内容、过期按下上下文、读取期间列身份和所属范围变化，以及原整表中格内便签继承来源。身份与范围变化含明确受控输入，不能代替真实账号验收。文字、来源和库数据按各任务范围读回。

入口限定在展开的普通表格，行内方式保持；原单元格操作与长文原件查看任务沿受影响范围复用验证。

新增任务登记在原Checks流程；当前准确提交CI、公开上传、服务器核验、部署、私人安装、真实托管账号、实体设备、输入法和作者实际使用仍待对应阶段验证。原型和实际源码分别记录，没有测量真人理解或耗时。本说明不表示网站或旧体验入口已经更新。
