# 材料较多时接着写

在原工作台的画布中持续写便签时，画布页不再反复生成它不会显示的大纲列表。“内容”大纲仍由原来的共享侧栏更新，打开后可查找最新文字并回到正确的卡片；直接打开单页白板时，大纲仍按原方式使用。没有增加操作步骤，也不改文字、保存格式或撤销规则。

本机用10、200、800张给定卡片旁的4万字符便签，完成连续键入、撤销重做、保存和新工作台读回。另在800张卡片的场景中延后合成保存请求，核对原侧栏能查到尚未保存的新输入，并选中准确目标；普通单页的标题修改、检索、保存重开也已核对。原宽窄窗资源文字检索和普通单页导航两项受影响任务通过。

同一台电脑、带记录器的无头浏览器中，800张卡片场景首字之后18次键入的处理时段中位数，原路径约5.9毫秒，源码候选约0.55毫秒；到下一动画帧的中位数约12.95与7.6毫秒。这里只说明该给定路径中减少了持续输入的重复工作，不能换算成实体键盘到屏幕的延迟。首字后的约100毫秒等待在原型对照中仍存在，此项没有解决或确定它的原因。

独立源码候选，本机任务与准确源码CI分开记录，当前CI尚未运行。首次源码合成任务的网络拦截器收尾错误已保留并修正，不算通过。未合并、部署、启动作者服务器QA或私人安装；输入法、实体设备、真人手感、长期使用及所有密集材料形状未验。
