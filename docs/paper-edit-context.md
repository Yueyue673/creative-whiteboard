# 认清正在编辑的长文

展开长文时，标题栏直接说明当前对象。有内容库来源的白板副本显示“编辑副本 · 来源记录：名称”；独立长文显示“编辑长文 · 标题”，改标题时随当前输入更新。正文与保存沿用原输入框，不增加一步操作。

“来源记录”是这份副本留存的名称，库中原件后来改名时不会覆盖它。需要看当前原件或比较修改时，仍用“来源与备注”的原入口。长名称最多占两行，完整文字可在指针提示中查看；极短窄窗口收起这段说明，保留操作按钮。普通便签和查看资料时的原角色说明保持。

这是独立源码候选。给定两篇同名、来源不同的长文，原型1360px/320px可以直接区分两份副本，减少为确认来源反复打开、关闭备注的动作。它不是真人理解速度的测量。最终源码1360px/320px完整任务本机通过，包含两份副本原选区、原生续写撤销重做、标题改动与撤销、长名称两行、来源后来改名、普通便签资料返回、230×220返回入口和保存新页读回；原长文工具与对话框任务也通过。对应CI、部署、私人安装和实体设备未验。
