# 从已收录的 CSV/TSV 接着写表格

在内容库只选中一份 CSV 或 TSV 文件，点“写表格”，再点“读取已选文件”，即可打开文字预览。可以先查看文件再关闭预览，原来的选择会保留。文件文字进入既有预览，由你核对分隔方式与“首行作为列名”，明确点“建成表格”后继续写，最后保存到内容库。无需先下载文件、打开外部编辑器或复制粘贴一遍。

原文件和库中条目保留，新表格独立保存，不会自动跟随文件更新。读取不会自动建表或保存；没有合适的单个文件选择时，原来的手写/贴入文字入口保持。选择多个文件不会暗中取其中一个，也不新做一套文件列表。

支持完整 UTF-8 小文件，以及带编码标记（BOM）的 UTF-16LE、UTF-16BE 文件。UTF-16 按文件标记识别，不自动猜测其他编码。文件不超过1MiB、文字不超过262144个浏览器文字单位，沿用既有100行、12列的新表格范围。读取完整文件，不使用已截短的文件预览；过大、超长、损坏编码、不支持的UTF-32标记或部分响应不会截掉一段来建表。CSV本身有引号问题时，完整文字仍可留在当前表单中修正。更大的表格继续使用原白板文件导入。

有编码标记的文件可沿同一个“读取已选文件”入口继续，无需先在外部转成UTF-8。解码不会改写原文件；预览文本框沿浏览器原行为将CRLF显示为LF，保存的表格仍按原行列与单元格内容核对。

等待读取时可继续写标题，后续标题输入和选区保持。改来源文字或首行设置会取消旧读取，格子已有后续输入时不替换。取消读取只停下这次读取；关闭表单、观察到文件信息或账号/工作区变化时，旧结果不能填入后来表单。读取15秒仍未完成会停止，并保留当前表格供明确重试；读取期间保存会先提示等待或取消，避免漏掉所选文件。

隔离核对范围包括完整长文件、CSV/TSV、原文件身份、明确预览/建表/撤回/保存、读取错误、后续输入与观察到的所属范围变化。新增任务登记原 `test:browser` / Check 和 `LIBRARY_CSV_TABLE_ENTRY_PROOF` 留存；准确当前提交CI、服务器QA、网站更新、私人安装、真实托管账号、外部应用集成、实体设备、输入法及作者实际使用仍待对应阶段。观察到的合成账号变化不代表真实托管账号验收。
