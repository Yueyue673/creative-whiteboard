# 从内容库取材料到指定格子

先在内容库选择卡片、无连线组合或文件，再回到普通表格，点目标格子。原来的“添加”菜单显示“库中所选”和资源数量，点击后把这一批副本放进该格子，并接着在第一份副本正文写作。

目标格子沿用原来的选中边框。库原件、其他格子和白板上的内容保留；一批取用可整体撤销、重做。已有宽屏拖放、便签和文件入口仍可使用。

窄窗中不必让内容库与展开表格同时可见，也不必先把材料放到画布再搬入格子。这个入口复用当前内容库所选，不另开选择器。宽屏并排时，原来的直接拖放仍很方便。

读取期间继续输入、换格子、关闭编辑或取消操作，会保留当前编辑并放弃迟到的取用。失败后可从原菜单重试。所选材料若已移出内容库，整批不写入，避免少一部分却像已完成。

格内副本目前不能表达画布分组或内部连线。含这类对象的组合整批保留在库中，提示使用原白板取用入口；不会静默丢掉分组或关系。

## 验证范围

独立合成任务覆盖1360和320宽窗口：指定非首格取用卡片与文件、正文接续、整批撤销重做、保存重开、原件及文件字节、等待期间取消和继续输入、资源变化、整批拒绝和网络失败重试。复用原单元格新增任务核对便签、文件、行列和取消菜单。

网络失败和只读/暂停范围变化为受控条件。没有访问系统剪贴板，也没有把原型菜单注入算作源码验收。新任务沿用原 Checks 流程登记；当前准确提交的 CI、服务器核验、部署、私人安装、实体设备、输入法与作者实际使用仍待对应阶段验证。本说明不表示网站已更新。
