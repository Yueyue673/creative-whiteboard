# 从原白板更新时，可以先继续写

内容库预览中的“原件 → 从原白板更新”仍先读取原白板，再展示组合差异，最后由你勾选应用。等待期间可以继续创作；开始写新便签、打开其他面板或在主窗口进行其他操作后，这次迟到的读取不会再弹出旧对照。新便签的文字、光标和撤销保持，需要比较时可重新进入原入口。

读取和应用前都会核对库中原件版本，以及观察到的编辑窗口和主窗口账号、工作区与权限。原件已改、加载/保存提示未处理、暂停或仅可查看时，保留原内容；已经打开的对照在面板内解释，勾选保持。已经提交并完成的请求若遇到所属位置或保存状态变化，会提示回原位置核对，不称为取消，也不自动重发。

这项处理不锁住整个工作台，不另建队列，也不改变收录、复用或更新的接口。对照展示本次读取的来源快照；应用前核对接收更新的库中版本，不声称来源白板在对照期间一直没有其他编辑。

隔离基线通过原生入口复现：暂扣来源读取时，新写的便签会被迟到面板替换。最终任务在1360×900与320×900合成资料上核对29项保护，包括后来输入、焦点和撤销、打开又关闭新面板、主窗口操作、新库版本、观察到的工作区变化、暂停/查看权限、正常单次更新，以及新浏览器读回。宽窗口还核对真实合成请求落盘后暂扣回执的说明。账号与权限是受控给定值，未代表真实账号切换；没有读取私人创作。

本机源码与原CI流程登记分开记录。当前准确提交CI、服务器QA、部署、私人安装、手机/实体设备、输入法及作者实际使用仍待对应阶段验证。
