# 启动后直接打开本机白板

先准备能运行的 Python 3.10 或更新版本。解压后的目录里如果有 `启动白板.cmd`，Windows 可以双击这个入口：原本机服务启动成功后，会请求系统浏览器打开白板页面，不必再输入启动命令、复制地址。

服务仍在启动窗口中运行。其他平台，或仍想手动打开页面时，照原方法运行 `python server.py`，再打开控制台显示的本机地址。也可以使用 `python server.py --open-browser` 请求自动打开。

如果浏览器未能打开，启动窗口会显示可手动打开的地址，服务继续运行。地址被占用时，本次启动会停下，保持原来的程序；不会直接打开占用该地址的页面。Windows 也可能把地址不可用报告为访问受限，提示会保留“占用或系统限制”两种可能，并指向原启动窗口或更换端口的方法。[更换本机端口](usage.md)

这个入口沿用原来的数据目录规则，不迁移、不覆盖已有白板。设置过 `CREATIVE_BOARD_DATA_DIR` 或 `CREATIVE_BOARD_PORT` 时仍沿用它们。默认命令不自动打开浏览器；账号版、服务器部署和私人安装不通过此入口自动操作。

当前开发分支新增此入口；默认分支下载是否包含它，以解压后的实际文件为准。原型与源码验收分开：已完成六项可返回原型对照，包括实际命令入口、写作保存读回、浏览器不可用和地址占用；浏览器提供者由记录器替代，再用隔离无头浏览器完成原生操作。源码六项单元方法按受影响路径核验完成；最新源码已通过冷启动、原生写作保存和重新打开的完整合成任务，准确CI尚未运行。Windows资源管理器实际双击、系统默认浏览器及下载安全提示、陌生电脑和真人上手体验未验；此处没有调整系统安全设置。
