# 从公开示例试一次复用

在空白页点击“试用一组公开示例”，会把仓库已有的“从想法到画面”四块内容和三条连线放进当前白板，自动全览。它不会自动出现；已有内容的白板不显示此入口。原来的写便签、表格、文件和内容库入口仍可直接使用。

示例可编辑，也可一次撤销回到原空白页。想体验复用，选中需要的内容，点“保存到库”或按 Ctrl+Shift+L；再开另一张白板，从内容库预览并取用。之后修改自己的副本，库中原件和原白板保持。

示例来自项目原有的公开入门材料。当前属于独立源码候选。宽窄完整任务已核对收进库、取用副本、续写、撤销及保存重开，短窄窗入口和主题文字颜色也已核对。对应CI、部署、私人安装及实体体验尚未验。
