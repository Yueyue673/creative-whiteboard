# 先找到最近保存的内容

在内容库的“内容顺序”中选“最近保存优先”，可以把当前范围内最近保存、维护过的内容放在前面。忘了准确名称时，可以先读这几项，再勾选取用副本。

默认保留“原来顺序”。排序沿用当前文件夹和查找范围，改变的只是当前窗口的列表顺序；不会移动文件夹、修改原件或隐藏较早内容。没有保存时间的旧项目保留原先相对顺序，排在有时间的项目之后。这里不把文件在磁盘上的修改时间当作收录时间。

选好内容后，沿用预览、“返回内容库”和添加所选的原操作；取用到白板后继续写，原件保持。切回“原来顺序”可恢复原列表顺序。
