# 第一次使用创作白板

这是在浏览器里使用的笔记与资料整理工具。你先在自己的电脑上启动程序，再打开白板；不是打开 GitHub 就能直接编辑。

[下载本机版 ZIP](https://github.com/Yueyue673/creative-whiteboard/archive/refs/heads/main.zip) · [返回首页](../README.md) · [完整操作说明](usage.md)

## 先准备什么

- 一台电脑，以及 Chrome 或 Edge 浏览器。手机和平板的复杂表格触摸输入仍有已知问题，建议先在电脑上使用。
- [Python 3.10 或更新版本](https://www.python.org/downloads/)。Python 用来启动本机程序，平时写便签不需要写代码。本机版无需账号，也不需要安装 npm。

Windows、Linux 的本机运行已核对；macOS 尚未完成实机验收。[版本和平台说明](status.md)

## 下载、启动、打开

1. **下载并解压。** 打开下载得到的 ZIP，把里面的项目文件夹完整解压出来。进入能看到 `server.py` 的那一层文件夹。
2. **在这个文件夹打开终端。** Windows 可以在文件夹的地址栏输入 `powershell` 并按 Enter；也可以使用系统的“在终端中打开”。运行下面的命令：

   ```sh
   python server.py
   ```

   系统使用 `python3` 时，改成 `python3 server.py`。如果提示找不到 Python，先完成 Python 安装，再重新打开终端。**使用白板期间保留这个终端窗口。**
3. **在浏览器打开白板。** 访问 [http://127.0.0.1:18746/](http://127.0.0.1:18746/)。这是你自己电脑的地址，不是需要注册的在线服务。

Windows 也可右键项目里的 `启动白板.ps1`，选择使用 PowerShell 运行。当前下载的是本机版；带账号的服务器版本需要另行部署，不在这里安装。[两种版本的区别](status.md)

## 写第一张便签

在白板空白处双击，输入一条自己的记录。点击空白处结束编辑；单击便签可以移动它，双击继续写。内容会自动保存。

想先看看怎么整理，把项目中的 [examples/getting-started.json](../examples/getting-started.json) 拖进画布。它是一份公开的演示示例，可以移动、修改和撤销。

![真实演示示例：左侧内容库保存“观察与分镜”，新白板放入了同一组便签、镜头表和连线。](screenshots/readme-reuse.png)

想把这组内容留到下一次，跟着 [保存一组 → 放到新白板 → 与原件对照](reuse.md) 做。想看着原资料继续写，打开两张白板后，点右上角的「左右分栏」。

## 关闭以后，怎样接着用

等保存完成后再关闭页面和启动程序。下次在同一个项目文件夹重新运行 `python server.py`，再打开同一个浏览器地址，继续原来的内容。

内容默认保存在项目的 `data/` 文件夹。备份时一起保留它，以及放在其他目录、被白板引用的原文件。历史记录不能代替独立备份。外观与阅读位置保存在当前浏览器，清除网站数据会影响这些偏好。

本机版没有公网账号保护，不要直接开放到互联网。同时在多个窗口修改同一白板可能产生保存冲突，不是多人实时协作工具。[操作与保存说明](usage.md)
