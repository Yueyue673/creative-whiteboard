# 试摆后回到原位置

选中两块以上内容，在原“对齐与间距”里展开“试摆与返回”，先点“记住当前摆法”。试着排列、移动或补写以后，选回这几块内容，点“回到记住的摆法”，只恢复记住的位置，后来写的文字、调整的尺寸、连线和新增内容保留。选中分组时，一并记住当时的组内内容位置；后来新增的内容留在当前位置。返回操作可以用白板原撤销、重做恢复。

这是当前标签、当前这次打开白板的临时记录，只记住最近一次摆法；“改记当前摆法”会替换它。重新载入、切换白板或重新打开标签后，需要重新记住，不保存到白板文件或浏览器偏好，不承诺跨设备同步。默认排列工具保持原样，不需要试摆时可收起这一小节。

所选对象必须与记住时相同。记住的对象被移除、编号重复或类型改变时，不部分套用位置；保存冲突和过时窗口操作也不会移动后来打开的白板。

当前为尚未上传、尚未部署的独立源码切片。1360px和320px本机合成任务核对原生排列、续写、位置返回、原撤销重做、真实保存与新页读回。十项保护覆盖分组与新内容、空操作、不同选择、移除/类型变化/重复编号、无效改记保留旧记录、旧窗口、冲突和切换白板。物理设备、输入法与长期体验未验。准确提交CI尚未运行，公开上传仍按本切片及祖先的具体授权边界处理。
