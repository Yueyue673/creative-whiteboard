# 从库中原件找回用过的副本

在工作台的内容库中预览一份组合原件，展开“用过的白板副本”。列表按副本保存的原件记录查找；改了标题、补写了正文，也能找到。同名的另一份原件不会混进来。每项显示白板名、目录和块或表格内位置，点击后在原白板打开；跨白板沿原“返回刚才”回到原稿。当前白板正在写作时，沿原资料对照查看副本，返回后保留原输入框、选区和文字撤销。

查询只读当前账号有权读取的工作区，桌面版只读当前数据目录。只查当前保存的白板与组合原件记录，不查历史版本、回收站、私人草稿、文件路径引用或未记录原件的旧复制。当前正在写的白板用其内存内容替换已保存的结果；另一个已打开目标在点击时核对其实际内存副本，其他窗口尚未保存的修改可能不会显示。副本已删除、改变原件或身份有歧义时不打开别的内容。原稿保存冲突时留在当前页面。

这是按需的有界查询，不是全历史使用清单。每次最多检查500份白板、8 MiB正文、100000个结构片段，递归最多16层，最多返回40处；服务端另有限时，当前白板核对也有限时。达到上限或遇到无法完整读取的记录时明确显示“尚未查完全部范围”；空结果仅表示当前支持范围暂未找到。查询不更新原件、不同步副本、不新增持久索引。

源码本机验收使用独立合成数据：1360px与320px的真实原界面任务验证改名副本查询、打开、原稿返回、反向选区、原生文字撤销/重做及保存读回。保护场景覆盖当前未保存副本、同页资料对照、表格内定位、延迟取消、失败重试、部分范围、错误原件/格式、账号/工作区绑定、目标变化和保存冲突。服务端单测核对只读范围、成员权限、预算与并发读取。账号绑定浏览器场景使用受控模拟响应，不能代替实体设备、真实托管浏览器或长期创作体验。

浏览器任务为 tests/browser-library-copies.cjs，通过 LIBRARY_COPIES_PROOF 留独立JSON与截图。它只在原npm浏览器任务中注册一次；原试摆检查也修正为一次注册，保持其证据归档。准确提交CI尚未运行；本切片尚未公开上传或部署，继续遵守各批具体上传授权及祖先依赖。
