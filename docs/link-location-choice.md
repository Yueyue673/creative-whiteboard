# 先辨认格内内容的位置，再建立关联

在原“关联内容”列表中，格内内容的名称和白板名下方会显示所在表格、行列及列名。表格再嵌套表格时按实际层级显示路径；原来的“查看”和“引用”操作保留。顶层内容保持原列表形式。

这份位置只从当前读取到的表格结构生成，不写进正文，不替代引用目标编号。改名或移动后的新列表使用新位置；已写入的引用仍按原目标编号解析。搜索仍按原来的内容名称和白板名称，位置提示不扩大检索范围。

同名关联的选择窗口和白板反向引用列表也使用相同位置。长位置可折行，列表中最多显示三行，完整文字保留在提示中；同名表格、同一格内同名内容等仍可先查看原资料再决定。
