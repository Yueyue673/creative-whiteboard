# 版本对照发生变化时，保留原稿再核对

“查看库中更新”和“用这块内容更新原件”仍分别作用于当前白板副本和库中对应原件。勾选需要的字段，再应用；正常更新和原有撤销方式保持。

对照已经打开后，若进入保存冲突、账号暂停或只有查看权限的状态，应用会停止，原稿、原件和勾选保持。面板内说明原因，处理原提示后再核对。副本内容、库中原件、白板对象或所属账号、工作区改变时，也会停止旧对照，避免把较早的比较用于后来正在处理的内容。

已经提交的请求需要按实际结果处理。若原位置的更新已完成，但等待回执期间所属位置发生变化，仍打开的面板会提示回原位置核对结果；不会把它称为已取消，也不会自动再发一次更新。
