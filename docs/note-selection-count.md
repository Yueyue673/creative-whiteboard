# 在格式化与摘录前，看清当前文字范围

在普通便签的正文、自己的补充或备注中选中文字，再打开原来的 Aa 面板。面板会标明这次操作的字段，并显示所选字符数；例如“正文 · 已选 14 个字符”。没有选择时会说明“未选中文字”。这样可以在应用格式或把片段存到内容库前，先核对操作范围和片段长度。 面板打开后重新选字，可以直接沿原按钮存到库；没有选区时，摘录按钮会停用。

范围是当前输入框中看得见的所选文字，包括空格和换行。组合表情、带重音的组合字母按一个可见字符计数；输入中可见的 Markdown 符号也计入。白板关联按编辑框里显示的名称与括号计数，原始关联目标保留。正文、补充和备注分别计算，附件和其他字段保持各自的范围。

提示沿用原面板和选区，不更换输入框，不写入创作内容或编辑历史。格式化后提示会随原选区更新；进入原“所选文字存到库”后，仍沿原摘录流程。特别长的选择暂不统计；浏览器未提供字符划分能力时保留字段与选择提示，不给出不准确的数字。这里用于所选文字范围，没有整篇字数或录制时长结论。
