# 使用说明

先写几条内容，再整理它们的位置。无需先决定完整结构。

## 白板与内容库

白板用于编排，内容库用于保存和复用。可以在库中新建文字、导入文件、建立嵌套文件夹。选中白板内容拖进侧栏文件夹，或使用“收进库”；原白板保留。

组合可以整体放入，也可以进入预览后只挑其中几块。副本上的“来自…”用于定位原件、比较后更新某一边，没有静默双向覆盖。

## 复制和尺寸

选中便签后 Ctrl+C，切换白板后可以直接 Ctrl+V，无需额外点击画布。鼠标在画布上时粘贴到附近；不在画布上则整组居中。右键菜单粘贴使用右键位置。连续粘贴会错开。便签四角用于调整外框，文字大小不变。

## 资料阅读

双击库中资料或使用卡片上的放大查看。JSON 支持内容、结构、原文三种视图。HTML 在受限 iframe 中打开。对本地 HTML，默认只允许访问所在文件夹内的相对资源；需要共享父目录资源时，可将 `CREATIVE_BOARD_PREVIEW_ROOT` 设置为明确的资料项目根目录。该配置仅在文件确实位于指定根目录内时使用。

音视频恢复进度但不会自动播放。JSON 和受支持的本地 HTML 记住阅读位置。浏览器清除网站数据会清除这些记录。

## 怎样调整显示大小

| 你想调整什么 | 在哪里操作 | 会改变什么 |
| --- | --- | --- |
| 工具栏、按钮和侧栏文字 | 更多 → 界面大小，80%～125% | 界面整体大小；画布中的内容比例不变 |
| 侧栏宽度 | 同一设置中的侧栏宽度，260～520 px | 文件名和目录的显示空间 |
| 整张白板 | Ctrl＋滚轮；或右下角加减按钮 | 一起放大或缩小便签、连线和资料 |
| HTML、JSON 内部的内容 | 文档顶部的比例按钮 | 文档的阅读大小；白板比例不变 |
| 便签或表格外框 | 拖动四角手柄 | 宽高和文字换行；字号不变 |

**选中内容后，点击底部工具栏的“字号”，可分别调整标题和正文字号（10～72 px）。** 多选可以一起调整，重置恢复默认值，Ctrl+Z 可撤销。字号随内容保存、复制；编辑与阅读使用相同字号。放大白板只是临时改变观看比例。不要用浏览器的整页缩放替代这些操作，否则整个工作区都会变大。

## 标签页与左右分栏

点击标签栏的“＋”，选择已有白板或新建一张。点击标签切换；每张白板保留自己的缩放、选择和阅读现场。拖动标签调整顺序，关闭标签只关闭视图，不删除白板。

点击顶部“左右分栏”，便可同时查看两张白板。右侧尚未打开内容时，用右侧“＋”选择。拖动中间分隔线调整左右占比，双击恢复各半。标签右键选择“移到另一侧”，也可以直接把标签拖进另一侧标签栏。点击“合并分栏”会将标签放回同一栏。

刚点击哪一侧，顶部的内容库、AI 整理和更多操作就作用于哪一侧。活动栏有深色下划线。Ctrl＋Tab 切到本栏下一个标签，Ctrl＋Shift＋Tab 返回上一个。

在来源白板选中内容后 Ctrl＋C，切到目标标签 Ctrl＋V 即可。正在输入文字时，先按 Esc 结束编辑。复制的是独立副本，组合内部连线会一起保留。

重新打开工作区会恢复标签和分栏比例。浏览器清除网站数据后，这些布局偏好不会保留；白板文件仍在本机。关闭有保存冲突的标签时，会保留标签和修改，让你先处理冲突。

需要独立窗口时，用“更多 → 在独立窗口打开”。同一白板被两个窗口同时修改时不会自动合并；遇到冲突先另存自己的修改，再读取最新版本。

## 将内容放进表格单元格

双击要写的单元格，会直接进入这一格编辑。加行、加列和完成编辑都在表格顶部的同一条工具栏里；列名可直接修改，拖行号或列名旁的手柄调整顺序。

表格保留你设定的外框大小，空行不会因为结束编辑而缩成细条。内容较多时在表格内部滚动。需要让高度跟随内容时，主动选择表格工具栏的“更多 → 按内容调整高度”；以前被压小的表格也能用这个操作恢复。

- **便签：** 选中便签 Ctrl＋C，双击表格进入编辑，点击目标单元格的文字区域后 Ctrl＋V。标题和正文作为一块独立内容保留，可以直接改。
- **音频、视频或图片：** 从内容库或电脑文件夹拖到单元格。一个格子可以放多项；音视频可以直接播放。
- **库中的组合：** 拖到单元格后，里面的内容会逐块放进去。分组框和连线不放入单元格。
- **取出或移除：** 编辑表格时，附件下面有“取出副本”和“移除”。取出副本会在表格右边生成内容块，原格子仍保留。

行列调换时，附件跟着所在的格子移动。删除行列会一起删除其中内容，可以撤销。JSON 导出保留附件；CSV 只包含单元格文字。嵌入的表格先显示摘要，取出到白板后可继续编辑。

长文不需要一直手动往下滚：输入到可见范围之外时，便签或表格的滚动区域会跟随光标。用方向键返回前面的文字时也会跟随。

## 自己整理时的基本规则

- 单击选择，双击编辑。输入框内的快捷键作用于文字，结束编辑后才作用于内容块。
- 白板负责当前编排，内容库保存可复用内容。先写到白板、以后收进库也可以，不必提前设计完整分类。
- 文件夹负责存放位置；标签可以补充不同角度的分类，不需要为每个标签再建一个文件夹。
- 从内容库放到白板的是副本。需要把修改带回原件时，打开“来自…”对照后再决定更新哪一边。
- Ctrl＋Z 用于撤销刚才的操作；更早的误改可从“更多 → 恢复与历史记录”寻找。记录有数量和容量限制，重要资料仍需独立备份。

## 文件位置与配置

默认所有工作数据保存在项目下的 `data/`，此目录不会提交到 Git。

| 位置 | 保存的内容 |
| --- | --- |
| `data/内容/` | 每张白板的 JSON 文件 |
| `data/目录.json` | 白板的文件夹关系 |
| `data/素材目录.json` | 内容库目录及文件引用 |
| `data/素材文件/` | 上传的文件 |
| `data/历史记录/`、`data/回收站/` | 可恢复的历史和删除记录 |
| `data/AI待审核/` | 等待确认的修改提案 |

`CREATIVE_BOARD_DATA_DIR` 可以指定数据目录，`CREATIVE_BOARD_PORT` 可以修改默认端口 18746。设置环境变量后重新启动服务。例如在 PowerShell 中：

```powershell
$env:CREATIVE_BOARD_DATA_DIR = Join-Path $env:USERPROFILE 'CreativeWhiteboardData'
python server.py
```

如果已经有内容，先停止服务，把原来的整个 `data/` 复制到新位置，再更改配置。指定空目录会打开新的空工作区，不会自动迁移旧资料。

浏览位置和界面大小保存在浏览器本地存储。换浏览器或清除网站数据后，这些偏好不会保留。
