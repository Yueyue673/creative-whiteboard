# 使用说明

先写几条内容，再整理它们的位置。无需先决定完整结构。

## 白板与内容库

白板用于编排，内容库用于保存和复用。可以在库中新建文字、导入文件、建立嵌套文件夹。选中白板内容拖进侧栏文件夹，或使用“收进库”；原白板保留。

组合可以整体放入，也可以进入预览后只挑其中几块。副本上的“来自…”用于定位原件、比较后更新某一边，没有静默双向覆盖。

## 复制和尺寸

选中便签后 Ctrl+C，在另一处 Ctrl+V。鼠标在画布上时粘贴到附近；不在画布上则整组居中。右键菜单粘贴使用右键位置。连续粘贴会错开。便签四角用于调整外框，文字大小不变。

## 资料阅读

双击库中资料或使用卡片上的放大查看。JSON 支持内容、结构、原文三种视图。HTML 在受限 iframe 中打开。对本地 HTML，默认只允许访问所在文件夹内的相对资源；需要共享父目录资源时，可将 `CREATIVE_BOARD_PREVIEW_ROOT` 设置为明确的资料项目根目录。该配置仅在文件确实位于指定根目录内时使用。

音视频恢复进度但不会自动播放。JSON 和受支持的本地 HTML 记住阅读位置。浏览器清除网站数据会清除这些记录。

## 双开与恢复

“更多 → 在新窗口打开”可并排使用不同白板。同一白板出现版本冲突时，先另存保留修改，再决定怎样合并。

“更多 → 恢复与历史记录”可取回历史内容。记录最多每个对象40份，并受容量约束；不是永久完整的版本库。

## AI 协作

从“更多 → AI 整理与审核”导出需要整理的内容及版本号，让 AI 返回 `creative-board-proposal` 格式的提案，再导入审核。所有修改默认不勾选。旧版本提案不能直接覆盖新内容。

提案格式与处理逻辑见 `workflow_backend.py` 与 `wfApplyProposal`。接入前先在临时白板测试，并保留原始资料。
