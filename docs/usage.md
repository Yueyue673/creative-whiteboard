# 使用说明

先写几条内容，再整理它们的位置。无需先决定完整结构。

## 便签外观、格式与关联

双击便签后，编辑栏的“外观”可以直接换颜色，选择素面、横线或方格纸，也能输入自己的十六进制颜色。换色时正在输入的内容保持原位；颜色和纸面选择可以撤销。

“Aa”打开文字格式工具。选中文字后，可以应用粗体、斜体、删除线、高亮、行内代码；标题、引用、列表、任务列表和代码块作用于文字或段落。Ctrl+B、Ctrl+I 也能使用。“预览”显示阅读效果，再点“继续编辑”返回原文。沉浸编辑中也有这些工具。

文字保存为 Markdown，便于导出和继续编辑。新便签默认支持 Markdown；已有便签保持原来的纯文本显示，使用格式工具或勾选“按 Markdown 显示”后才启用。原始 HTML 按文字显示；Markdown 图片不会自行加载外部图片，图片仍通过已有附件功能加入。

“关联”可以搜索其他便签，包括其他白板里的内容。选择后在光标处插入双向链接；阅读时点击链接可以跳转。面板下方列出引用当前便签的内容。通过选择插入的链接绑定白板和便签编号，目标改名后仍能找到它；显示文字保留你自己的写法。也可直接写 `[[便签标题]]`，标题重复时需要从“关联”选择明确的目标。链接不会自动新建内容。

关联面板按需读取可访问的白板；读取失败会明确说明列表可能不完整。文字只由你编写，格式工具和关联选择不会生成正文。

## 白板与内容库

白板用于编排，内容库用于保存和复用。可以在库中新建文字、导入文件、建立嵌套文件夹。选中白板内容拖进侧栏文件夹，或使用“保存到库”；原白板保留。

没有打开白板时，内容库仍可新建、编辑、搜索和查看恢复记录。选中库中的内容也能提供给 AI 查资料；这些操作不会偷偷创建一张白板。准备编排时，再用标签栏的“＋”打开或新建白板。

白板暂时打不开时，画布会说明原因，可以直接重试或选择另一张。内容库仍可使用。切换时会先等当前修改保存；保存失败就留在原白板，保留文字。读取另一张失败时，已打开的内容仍保留，可以继续编辑。连续选择几张白板时，以最后一次选择为准。

文件正在读取或上传时，可以切换到其他标签，内容会继续放到原来选定的白板。关闭原标签时，会先等导入完成并保存；重复点击关闭不会影响旁边的标签。单窗口切换白板或重新读取，也会先完成当前导入。较慢的导入会显示“正在添加素材…”，关闭整个窗口时会提示仍有任务未完成。

内容库中的文件夹在导入途中改名或移动，文件仍会跟随原文件夹，包括另一窗口进行的调整。刷新后侧栏也会继续显示同一个文件夹。同名新文件夹不会接收旧导入；原文件夹被删除时，新文件保留在内容库根目录并提示重新放置。导入时去看别的文件夹，完成后不会强行跳回原位置。撤销文件夹改名时，后来导入其中的文件也一起跟回去，媒体文件不复制、不搬动。

等待保存时继续导入内容，也会一并保存后再切换或关闭。最后一次保存失败，就留在原白板保留新增内容。另存副本期间继续编辑或导入时，副本照常保存，当前窗口保留后续修改；不会用较早的副本替换新内容。

向表格上传附件时，移动行列、撤销或重做，附件仍会跟随原单元格。原来的内容块或单元格已移除时，文件仍保留在内容库，并提示你重新放置；新建在同一位置的空格不会接收旧附件。库中图片尚未读取完时切换白板，也不会改变原先选定的目标。

选中内容后，外框旁会出现操作栏，不会挤占标题或正文。“拖出副本”用于按住拖动，把副本放进表格、内容库文件夹或另一侧白板；⋯ 打开操作菜单。复制到剪贴板仍使用 Ctrl＋C 或菜单里的“复制内容”。复制的文字可以独立修改，音视频和图片仍引用同一个文件。

组合可以整体放入，也可以进入预览后只挑其中几块。副本的右键菜单中有“来源与版本”，也可以在编辑时打开“说明”找到库中原件。对照后再决定更新哪一边，修改不会自动覆盖原件。正文、备注和音视频时间标记可以分别勾选；更新保留白板上的位置与尺寸，其他副本仍独立。原件更新可在内容库撤销，白板上的更新用 Ctrl＋Z 撤销。

确认更新后，等待期间不会重复提交。需要继续看其他内容，可以关闭这个窗口；之前的更新完成不会关闭新窗口。更新失败时，勾选项会保留，可以调整后重试。

在内容库选中项目，按 Ctrl＋Enter 放到当前白板。还没有打开白板时，会先让你选择目标，也可以新建一张。取消选择或添加失败时，组合预览和勾选会保留，可以直接重试。等待目标加载时再切换标签，内容仍放到最初选定的白板，不会跟着切换。整批内容可以在目标白板一次撤销，库中原件保留。

文件夹和内容都采用单击选择、双击打开。方向键可以移动选择，Enter 打开。路径中的文件夹可直接点击跳转。侧栏底部用于新建和导入；右上角的“⋯”可显示文件夹树、刷新或查看帮助。侧栏的显示状态和所选页面会在重新打开时恢复。

左上角的侧栏图标控制整个窗口共用的侧栏，也可按 Ctrl＋\。分栏时，“本页内容”跟随当前操作的白板；库中内容会放到当前栏。拖动侧栏右边缘调整宽度，无需打开设置。

“外观”里可以选择深灰、纸白或蓝灰，也可以自己调颜色。改变工具与侧栏的颜色时，文字、输入框、选中状态和键盘焦点会一起适配，避免浅色文字落在浅色背景上。画布颜色可以独立调整，已有便签的颜色和内容保持不变。选中边框旁有一条细的对比边缘，内容叠放时也更容易辨认。

## 复制和尺寸

普通滚轮滚动内容，在画布空白处移动视野；只有 Ctrl＋滚轮才以鼠标为中心缩放白板。Shift＋滚轮可横向移动空白画布。指针在图片、表格、JSON 或 HTML 内时也遵循这条缩放规则。

点进白板中的 HTML 网页后，也可以直接按 H/V 切换手形与选择、按住空格拖动画布，或用 Ctrl＋加减号调整白板比例。Shift＋1 查看全部，Shift＋2 放大选中内容，Ctrl＋Tab 切换同栏标签。网页输入框中的文字仍正常输入；点进另一栏的网页后，顶部工具也会跟随那一栏。

选中便签后 Ctrl+C，切换白板后可以直接 Ctrl+V，无需额外点击画布。鼠标在画布上时粘贴到附近；不在画布上则整组居中。右键菜单粘贴使用右键位置。连续粘贴会错开。便签四角用于调整外框，文字大小不变。

在内容库里选中内容，Ctrl+C 复制，进入另一个文件夹后 Ctrl+V 粘贴。文件夹也能复制，包括子目录与空文件夹；同名的副本会在目录名称后标明“副本”，便签原文和备注不改。音视频与图片继续引用同一份原文件。

右键复制后马上粘贴到内容库或画布，工具会等待本次复制完成；连续复制时使用最后一次选择的内容。侧栏和同一窗口里的所有白板标签共用这一顺序，关闭来源标签也不会打断复制。取消剪切后，原件保留，未完成的复制动作也不会重新恢复剪切状态。

等待复制时，又在输入框或白板的文字阅读、编辑区域里复制、剪切了一段文字，后来的文字会保留，文字编辑仍按平常的方式进行。选中文字的加粗等格式也会保留在剪贴板里，放到白板上则作为文字便签。粘贴等待期间，目标文件夹改名或移动，内容会跟随原文件夹；原文件夹已删除时，会提示重新选择位置。同名的新文件夹不会接收这次粘贴。等待期间去看其他文件夹，完成后也不会把你带回原来的位置。

Ctrl+X 先标记待移动的内容，再到目标文件夹粘贴；粘贴成功才改变位置，按 Esc 可以取消。不能把文件夹移进自己。剪切后如果原件又被修改，工具会请你重新剪切，避免把新修改一起移动。在内容库按 Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。另一窗口完成剪切后，原窗口会更新目录；正在编辑的窗口会等你结束编辑。

从内容库粘贴到白板，会放入独立的内容副本；从白板复制后粘贴到内容库，会收录整组选中的内容及内部连线。直接在内容库粘贴文字，也可以积累自己的记录。文字字段里的复制粘贴仍正常编辑该字段。AI 的修改提案不会通过粘贴写进内容库。

在侧栏列表里用上下方向键选择，Home / End 到开头或末尾，Enter 打开，F2 编辑，Alt＋上方向键返回上一层。进入文件夹、刷新或关闭预览后，焦点会留在列表；刷新也保留当前阅读位置。内容库中 Shift＋方向键连续选择内容，Ctrl＋方向键只移动焦点，空格切换该项是否选中；Shift＋F10 打开右键菜单。长列表的 End 会到全部内容的末尾。焦点在共享侧栏中，也能用 Ctrl＋Tab 和 Ctrl＋Shift＋Tab 切换当前栏的白板标签。

新放入的音频、图片、视频和文档使用不同的默认尺寸。音频不会占用大块空白；图片按自身比例显示。已有的手动尺寸不会被重新排版。需要让外框跟随内容时，在内容的 ⋯ 菜单选择“按内容调整大小”。

新建便签默认自动适应内容，长短文字、字号或图片变化都会更新高度，宽度保持当前值。很长的内容会在卡片内滚动。拖动四角手柄后改为固定尺寸；便签的 ⋯ 菜单可以随时选择“自动适应内容”或“固定当前尺寸”。已有便签保留原尺寸，需要时自行开启。

选中便签按 Enter 开始编辑；选中文件按 Enter 打开查看，F2 编辑这块内容。文件旁的正文可直接填写说明，不必先打开另一个面板。

焦点在按钮上时，Enter 或空格执行这个按钮，例如展开编辑、打开菜单或播放、暂停。此时不会误触便签编辑或空格拖动画布。字号输入框按 Enter 确认，焦点回到画布。

从侧栏打开的预览或编辑窗口关闭后，焦点立即回到列表。可以继续按方向键选择下一项、按 F2 编辑，后到的关闭事件不会把焦点拉回旧位置。

## 展开编辑

选中内容后，点击外框旁的展开图标，或在 ⋯ 菜单选择“展开编辑”。标题、正文、补充和备注可以在大空间直接修改；“补充与来源”里可改标签、来源和颜色。支持贴入、拖入和移除图片，表格也能直接修改单元格、增删和调整行列。这使用同一份内容，修改继续自动保存。

点击“返回白板”或按 Esc 关闭，保留原来的画布位置、内容块尺寸和便签阅读位置。图片会按原比例占用卡片可用空间，不会为了填满而裁切。需要让外框贴合图片比例时，使用“按内容调整大小”。

## 资料阅读

双击库中资料或使用卡片上的放大查看。JSON 支持内容、结构、原文三种视图。HTML 在受限 iframe 中打开。对本地 HTML，默认只允许访问所在文件夹内的相对资源；需要共享父目录资源时，可将 `CREATIVE_BOARD_PREVIEW_ROOT` 设置为明确的资料项目根目录。该配置仅在文件确实位于指定根目录内时使用。

关闭后可以立即打开另一份资料、继续搜索或展开编辑。旧窗口的清理动作不会移除新窗口里的网页或编辑区；较早的读取和搜索结果，包括失败提示，也不会改变后来打开的内容。

网页载入较慢时，会说明仍在等待；跳转后也会继续更新状态。遇到无法显示的页面，可以点击“返回原网页”继续查看原资料。旧页面里尚未结束的图片请求不会替换已经返回的网页；按 Esc 也可以直接退出阅读。

音视频恢复进度但不会自动播放。JSON 和受支持的本地 HTML 记住阅读位置。浏览器清除网站数据会清除这些记录。

音频和视频的进度条在窄内容块、表格单元格中也会显示。直接点击或拖动进度条即可定位；白板缩得较小时，点击播放器的时间，打开正常大小的播放控件。两处控制同一个播放器，收起时不会暂停。按 Esc 或点击外部即可收起，无需改变内容块的大小。

右上角通常显示“自动保存”，快速保存不会闪动，也不会让标签出现反复变化的圆点。保存持续较久时会显示“正在保存…”。如果保存失败或另一窗口改了同一文件，会明确提示并保留当前修改；有问题的标签显示感叹号。此时先处理提示，再关闭窗口。

长便签选中后，可以点击“展开编辑”图标。编辑窗口显示标题、正文、自己的补充和备注；按 Esc 返回时，画布保持原位置，不会自动移动或放大。

### 大素材怎样放进来

画布底部“导入”有两种方式。选择文件会上传到数据目录；“引用本地文件”只登记原位置，不复制文件。可以从文件资源管理器复制完整路径，每行一个，批量添加。大型视频可直接引用机械硬盘上的原文件。

把同一个文件放到几张白板或多个单元格中，不会复制媒体文件。重复上传相同内容，也会复用工具已保存的同一份文件；其他文件夹中可以有独立的目录项。引用外部文件不会减少读取原文件的开销，播放速度仍取决于硬盘、文件格式和电脑性能。

原文件移动后，在内容的 ⋯ 菜单选择“重新定位原文件”。此文件在各张白板上的引用会一起更新，正文、尺寸和连线保留。删除白板里的内容块不会删除原文件。

## 怎样调整显示大小

| 你想调整什么 | 在哪里操作 | 会改变什么 |
| --- | --- | --- |
| 工具栏、按钮和侧栏文字 | 更多 → 外观，80%～125% | 界面整体大小；画布中的内容比例不变 |
| 侧栏宽度 | 拖动侧栏右边缘；或外观中的侧栏宽度，260～520 px | 文件名和目录的显示空间 |
| 整张白板 | Ctrl＋滚轮；或画布右上角的加减按钮 | 一起放大或缩小便签、连线和资料 |
| HTML、JSON 内部的内容 | 文档顶部的比例按钮 | 文档的阅读大小；白板比例不变 |
| 便签或表格外框 | 拖动四角手柄 | 宽高和文字换行；字号不变 |

**选中内容后，点击底部工具栏的“字号”，可分别调整标题和正文字号（10～72 px）。** 多选可以一起调整，重置恢复默认值，Ctrl+Z 可撤销。字号随内容保存、复制；编辑与阅读使用相同字号。放大白板只是临时改变观看比例。不要用浏览器的整页缩放替代这些操作，否则整个工作区都会变大。

“更多 → 外观”可选择深灰、纸白、蓝灰主题，也可分别调整画布、工具与侧栏、选中状态和新便签颜色。设置会同步到本窗口各栏及其他已打开的窗口，并在下次打开时恢复。已有便签的颜色不会被主题覆盖。

选中颜色与画布太接近时，选中框、框选边界和正在连接的端点会自动使用更清楚的颜色。设置里仍保留你选的颜色，原有主题的选中颜色不变。连线说明也会随画布明暗调整文字颜色，说明原文和编排保持不变。

## 标签页与左右分栏

点击标签栏的“＋”，选择已有白板或新建一张。点击标签切换；每张白板保留自己的缩放、选择和阅读现场。拖动标签调整顺序，关闭标签只关闭视图，不删除白板。

点击顶部的分栏图标，便可同时查看两张白板。右侧尚未打开内容时，用右侧“＋”选择。拖动中间分隔线调整左右占比，双击恢复各半。标签右键选择“移到另一侧”，也可以直接把标签拖进另一侧标签栏。再次点击分栏图标，会将标签放回同一栏。鼠标停在图标上可以查看名称。

刚点击哪一侧，AI 和更多操作就作用于哪一侧，内容库也会把副本放进这一侧。活动栏有主题强调色的下划线。Ctrl＋Tab 切到本栏下一个标签，Ctrl＋Shift＋Tab 返回上一个。

在来源白板选中内容后 Ctrl＋C，切到目标标签 Ctrl＋V 即可。正在输入文字时，先按 Esc 结束编辑。复制的是独立副本，组合内部连线会一起保留。

重新打开工作区会恢复标签和分栏比例。浏览器清除网站数据后，这些布局偏好不会保留；白板文件仍在本机。关闭有保存冲突的标签时，会保留标签和修改，让你先处理冲突。

需要独立窗口时，用“更多 → 在独立窗口打开”。同一白板被两个窗口同时修改时不会自动合并；遇到冲突先另存自己的修改，再读取最新版本。

## 将内容放进表格单元格

双击要写的单元格，会直接进入这一格编辑。加行、加列和完成编辑都在表格顶部的同一条工具栏里；列名可直接修改，拖行号或列名旁的手柄调整顺序。

编辑单元格时，Tab 前往下一格，Shift＋Tab 返回上一格。到边界时会前往标题或“完成”，不会自动增添行列。点击空白或另一块内容也会结束当前编辑。

表格保留你设定的外框大小，空行不会因为结束编辑而缩成细条。内容较多时在表格内部滚动。需要让高度跟随内容时，主动选择表格工具栏的“更多 → 按内容调整高度”；以前被压小的表格也能用这个操作恢复。

将鼠标放到列名右侧边界，出现调整宽度的指针后拖动即可。阅读和编辑时都能调整，行高与表格外框保持不变；列宽随表格保存。双击边界恢复该列的默认宽度。

- **便签或白板上的文件：** 选中后，将内容旁的“拖出副本”拖到目标单元格。无需先编辑表格，原内容会保留。也可以 Ctrl＋C，双击单元格后 Ctrl＋V。标题和正文作为独立副本，可以直接改。
- **音频、视频或图片：** 从内容库或电脑文件夹拖到单元格。一个格子可以放多项；音视频可以直接播放。
- **库中的组合：** 拖到单元格后，里面的内容会逐块放进去。分组框和连线不放入单元格。
- **取出或移除：** 编辑表格时，先点一下要处理的便签或附件，它会出现细框，表格顶部工具栏会出现 ↗（取出副本）和 ×（移除）。按钮悬浮说明会显示这份内容的标题；鼠标经过其他附件不会切换对象。取出副本会在表格右边生成内容块，原格子仍保留。移除后可以 Ctrl＋Z 撤销。键盘 Tab 进入内容后，也可以 Shift＋Tab 返回工具栏操作。

行列调换时，附件跟着所在的格子移动。删除行列会一起删除其中内容，可以撤销。JSON 导出保留附件；CSV 只包含单元格文字。嵌入的表格先显示摘要，取出到白板后可继续编辑。

长文不需要一直手动往下滚：输入到可见范围之外时，便签或表格的滚动区域会跟随光标。用方向键返回前面的文字时也会跟随。

## 自己整理时的基本规则

- 单击选择，双击编辑。输入框内的快捷键作用于文字，结束编辑后才作用于内容块。
- 白板负责当前编排，内容库保存可复用内容。先写到白板、以后收进库也可以，不必提前设计完整分类。
- 文件夹负责存放位置；标签可以补充不同角度的分类，不需要为每个标签再建一个文件夹。
- 从内容库放到白板的是副本。需要把修改带回原件时，打开“来源与版本”对照后再决定更新哪一边。
- Ctrl＋Z 用于撤销刚才的操作；更早的误改可从“更多 → 恢复与历史记录”寻找。记录有数量和容量限制，重要资料仍需独立备份。

只是点进输入框、切换字段或查看内容，不会增加撤销记录，也不会清掉重做。真正修改后，在同一个字段里连续输入算一段编辑；结束编辑再按 Ctrl＋Z，可撤销这段修改。便签、表格、格内内容和时间标记的备注都遵循这条规则。

连续刷新内容库时，会显示较新的读取结果。保存尚未完成时，刷新会等它完成；较早返回的目录不会让已保存的重命名或移动退回原处。读取失败时保留当前目录。另一窗口造成保存冲突时，编辑窗口里的文字会保留，便于你核对后再处理。

编辑库中的内容或文件说明时，保存前会核对最新版本。你没改的字段会保留库中的新版本；双方改了同一处，会在原编辑窗口中并排显示“库中版本”和“我的编辑”。逐项选择后再点保存，没有选择的冲突不会写入。如果核对后原件又变了，需要重新选择。这个过程只使用两边已有的原文，不生成新句子。

原件或正在编辑的内容块被移除时，可以点“另存我的编辑”保留独立副本。媒体仍引用同一个文件，不会再复制一份大文件。存放位置会跟随原文件夹的重命名；原文件夹被删除后，先重新选择位置再保存。读取或写入失败时，输入仍留在编辑窗口中，可以继续修改和重试。

选中文件夹后按 F2，或从右键菜单重命名，会保留当前目录；正在文件夹里阅读时，路径会跟随它的新名称。另一窗口重命名或移动当前文件夹后，键盘焦点和滚动位置也会保留。选中的内容后来被移出当前列表时，会取消这项选择。同名的新文件夹不会接替旧文件夹的选择。

## 删除与找回

在白板列表中删除白板或文件夹前，工具会先保存本窗口里相关白板的修改。保存失败时取消删除，让你先处理提示。删除成功后，相关标签关闭；Ctrl＋Z 可恢复文件及原来打开的标签位置。删除最后一张白板后，工作区保持空白，内容库仍可使用。

另一窗口删除了你正在编辑的白板时，未保存的内容会留在原标签里，并出现“另存当前内容”和“恢复原白板”。先另存可得到独立白板。如果原件已在另一处恢复，当前草稿仍保留，不会自动覆盖恢复的版本；由你选择另存或查看恢复后的原件。

在内容库按 Delete，将所选内容或文件夹移入回收站。文件夹连同内部内容、子文件夹和空目录一起记录；退出后仍可在“更多 → 恢复与历史记录 → 回收站”找回，一次恢复原来的层级。白板上的副本和硬盘上的媒体文件保留。Ctrl＋Z 撤销本次操作，Ctrl＋Shift＋Z 重做。

删除前会重新读取内容库。选中的文件已被另一窗口移走时，会停下并提示重新选择；文件夹改名后仍会删除原文件夹，不会误删后来创建的同名文件夹。删除当前文件夹后，留在还存在的上层目录。等待删除完成时，如果你已经去了别处或选择了其他内容，会保留新的位置和选择。

恢复前会重新读取内容库。另一窗口后来写的新内容、备注和新建的同名文件夹会保留；恢复只取消对应内容的删除状态，并补回目录。若另一窗口在保存时又修改了目录，会提示失败，窗口保持打开，可以重试。以前单独移出库的内容也仍能逐项恢复。

“当前白板”和“内容库历史”分别可以保存自己的恢复点。选中旧记录后先查看原文，再勾选所需内容。白板历史可以添加所选内容或整份另存；内容库历史可以“另存勾选内容”，取得独立副本并保留当前版本。确实要替换时，选择“比较并恢复”，查看差异后再确认。搜索历史内容时，已勾选项会保留。

另存提交后，重复点击不会再建一份副本。保存失败时，原窗口保留，可以重试。等待保存时退出历史记录、打开其他编辑窗口或切换白板，已提交的副本仍会保存；完成后会保留你后来打开的窗口和当前位置。

删除记录和自动历史都位于工作数据目录中，不能代替独立备份。恢复媒体时继续引用原文件；原文件若已被另行移走，恢复目录不会重新下载或重建媒体。

## 文件位置与配置

默认所有工作数据保存在项目下的 `data/`，此目录不会提交到 Git。

| 位置 | 保存的内容 |
| --- | --- |
| `data/内容/` | 每张白板的 JSON 文件 |
| `data/目录.json` | 白板的文件夹关系 |
| `data/素材目录.json` | 内容库目录及文件引用 |
| `data/素材文件/` | 上传的文件 |
| `data/历史记录/`、`data/回收站/` | 可恢复的历史和删除记录 |
| `data/AI待审核/` | 旧版提案记录，只读保留 |
| `data/AI任务/` | 研究任务、所选背景、资料摘录和图像附件 |
| `data/参考资料/` | 单独保存的来源与研究回复 |

`CREATIVE_BOARD_DATA_DIR` 可以指定数据目录，`CREATIVE_BOARD_PORT` 可以修改默认端口 18746。设置环境变量后重新启动服务。例如在 PowerShell 中：

```powershell
$env:CREATIVE_BOARD_DATA_DIR = Join-Path $env:USERPROFILE 'CreativeWhiteboardData'
python server.py
```

如果已经有内容，先停止服务，把原来的整个 `data/` 复制到新位置，再更改配置。指定空目录会打开新的空工作区，不会自动迁移旧资料。

浏览位置和界面大小保存在浏览器本地存储。换浏览器或清除网站数据后，这些偏好不会保留。

## 自动尺寸与时间标记

新便签默认随文字增高，宽度保持方便阅读，最长为 1200 px，超出后在卡片里滚动。选中、结束编辑不会切换宽度。手动拖动四角后保留你的宽高；右键“自动适应内容”可恢复。更新前已经摆好的卡片不会自动改变，表格、分组和文件卡保留自己的尺寸规则。

导入 TXT、Markdown 或粘贴纯文字也会使用自动高度，保留原文。复制已有内容或导入已有白板时，会保留原来的尺寸和编排。

点击音视频时间旁的标记图标，在当前位置添加时间标记，填写名称与备注，点击列表可跳转。勾选“下次从这里开始”后，重开内容或按“重播”从此标记开始；“改为接着上次播放”恢复原来的进度续播。不会自动播放。表格中的音视频副本可以独立记录。

在进度条上按左右方向键前后移动 5 秒，按住 Shift 为 1 秒，Home / End 到开头或结尾。列表中用上下方向键切换时间标记，Home / End 到第一项或最后一项。时间标记能区分小数秒；填写超出时长的时间会就地提示，不会写入。窄分栏里，名称、时间和备注会改为上下排列；关闭后焦点回到播放器。

声音尚未加载出时长，或文件暂时无法播放时，原标记时间会保留，并提示这次时间修改没有保存。名称和备注可以继续编辑；加载恢复后再调整时间。

## 对齐与导航

Ctrl＋滚轮以鼠标为中心缩放，普通滚轮用于滚动或平移。Shift＋1 全览，Shift＋2 查看选中内容。H 切手形，V 切选择，空格加拖动临时移动画布。方向键微移，Shift 使用较大步长。拖动时 Shift 限制方向，Alt 创建独立副本；对齐参考线默认开启，按 Ctrl 临时关闭。多选后右键“对齐与间距”可排成一行或一列。外观设置能调整吸附、缩放速度和步长。

排列多个分组时，组内的内容会一起移动，原文和连线保留。可以按 Ctrl＋Z 一次撤销，再按 Ctrl＋Shift＋Z 重做。

按住方向键移动分组时，这次移动会始终带着原来的内容，经过其他分组也不会掉队。松开按键或改选其他内容后，开始下一次移动。一次连续移动可以一起撤销和重做。

拖动中按 Esc 会放弃这次移动、尺寸调整或 Alt 副本，并恢复开始前的位置与尺寸；之前的撤销、重做记录保留。框选时按 Esc 恢复开始前的选择。未松手时按撤销或重做，会先取消当前拖动；再次按才使用此前的记录。复制、删除、方向键微移或切换工具，也会先结束未完成的拖动。移动分组会带着组内内容一起走，正常松手后可以一次撤销整个移动。移动内容不会打断播放，也不会重新排列原有文字。
