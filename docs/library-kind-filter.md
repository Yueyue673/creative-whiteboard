# 按内容类型取用资源

内容库的“内容”选项默认是“全部类型”。需要只看图片、音频或某种创作容器时，选择对应类型；选回“全部类型”即可清除。现有名称与正文搜索、文件夹范围和“内容顺序”仍可一起使用。

筛选依据沿用列表已经显示的类型，包括便签、长文、表格、组合、图片、音频、视频、网页、PDF、JSON和其他文件。类型指资源本身；含音频的便签仍归便签，组合中的材料仍归组合。筛选不移动内容、改原件或清除已经选择的项目；取用沿原来的预览、选择和放到白板路径进行。

给定162项同名资源的宽窄原型中，原按列表浏览需要两次“显示更多”到两种格式的图片，一次选择图片类型即可只看这两项。原名称、备注与扩展名搜索仍可使用；没有测量真人用时或理解。最终源码1360px/320px完整任务本机通过，核对所有显示类型、其他文件夹与空结果、查询和排序组合、清除筛选后选择保留、真实PNG/SVG取用、原生撤销重做、继续写与保存新页读回，库原件和媒体字节保持。其他文件类型仅验分类，未在此播放或读取；原类型辨认和搜索范围任务也通过。当前未公开，对应CI、服务器QA、部署、私人安装、短低窗口和实体设备未验。
