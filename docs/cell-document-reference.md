# 在记录旁查看格内网页和 JSON

普通表格展开编辑后，选中带网页或 JSON 的卡片，在“更多”里点“在旁查看文档”。长文中的同类材料直接显示这个按钮。资料按需进入现有对照查看器；不必让每一格都预先加载文档。

宽窗可在资料旁继续写，窄窗用顶部“返回记录”接回同一输入。文字、选区和原生撤销保留；资料查看不替换当前表格或长文。网页沿原沙箱预览，JSON 沿原内容、结构、原文和阅读大小控制；在资料里的缩放不写成作者卡片的尺寸或格式。

这里查看原文件，针对它写的记录仍留在原卡片中。现有“打开文件”入口保留；普通文本继续沿原文件预览，PDF 等其他格式没有新增这项对照。没有新增接口、永久来源字段、创作格式或后台队列。

读取失败会显示原因，可先返回原输入，再明确重试。等待时返回并继续写，迟到的结果不会再打开旧资料。文件引用、卡片或列身份不再对应，或者观察到的账号/工作区尚未确认时，停止旧查看，保留原稿；不会按重复编号猜另一张卡片。

最终任务在1360×900与320×900的普通表格、长文合成资料中核对29项保护：真实HTML/JSON渲染、同一输入与选区、边看边写、原生撤销重做、JSON单次读取、取消迟到结果、重复编号/列身份拒绝、给定读取503后返回和重试，以及原文件字节、库资源、格内文件引用与保存读回。状态和网络故障为受控给定条件，不代替真实账号、网络环境、实体设备、输入法或作者长期使用。

本机源码与准确CI、服务器QA、部署、私人安装分开记录；本次没有执行当前准确CI及后续发布阶段。
