# 在内容库表格末尾增加字段

编辑内容库里的普通表格，或点“写表格”新建一张，在格子下方点“加一列”。新列的列名和格子起初为空，焦点进入新列名，填写后仍需点“保存到内容库”。原列、格内资料、标题、说明、补充和备注保留原输入框；不必先放到临时白板再收录。

“撤回新增空列”只移除本次编辑新增、仍为空的末列。列名或任一格子已有文字、资料，或对应发生变化时，会保留整列并提示原因。它不删除原列。加行、加列可以交替进行；撤回其中一项时，另一项及已有文字保留。组合中切换内容再返回，草稿继续保留。Esc 也会保留尚未保存的结构改动，明确点“取消”才放弃。

这个入口面向最多100行、12列、各行格子完整对应的普通表格。第12列可以新增，达到上限后按钮停用。旧表没有列编号时继续保持原格式，不补写历史编号。已有行不齐、列编号含糊，或逻辑列之外仍有格内资料时，停止加列并保留现状，供回到白板核对。已有更大表格不会被截断。删除或移动已有行列、编排材料仍沿白板原路径。

从表格文本开始时，先核对并“建成表格”，再增加字段。原建表撤回会保留后续结构改动；先撤回仍为空的新列、行，才能沿原入口返回建表前的格子。已有输入不会被自动清掉。

保存沿原内容库最新版本核对。另一处同时改了表格文字、行列对应或格内资料时，先对照完整版本，再明确选择；后来又更新，旧选择失效。原文件、附件引用和未改字段保留，独立更新的几何属性和目录信息继续合并。已经放到白板的旧副本保持原样，之后取用的新副本带上保存后的字段。

这是独立候选源码的用法，尚未代表默认版本、网站或私人安装已更新。本机合成核对包含宽屏和320宽视口，不代替手机、真实账号或作者的实际创作体验。准确提交 CI、服务器 QA 与发布另行记录。
