# 挑选媒体材料时看见已存回看时间

同名媒体材料可能来自不同时间。单个媒体材料已经保存明确的重播起点时，内容库列表会增加一条“音频 / 视频 · 重播起点”说明，可以直接按时间辨认。原“查看已选”也保留这条说明，再沿“放入所选”取用。

名称、原话、类型筛选、资源顺序和取用方式保持。说明只读取资源中明确保存的起点，刷新后跟随已存内容更新。它不根据上次播放位置猜时间，不改名或写回资源，也不表示文件已裁切或设置了结束时间。

普通文件、纯文字、多块组合，以及起点缺失、时间无效、标记编号重复、媒体对应不明确的材料，保持原来的列表说明。需要时仍可沿原预览查看完整内容。

## 验证范围

1360×900与320×900的隔离合成任务通过12项保护：同名同备注材料按时间区分、零起点、无效与歧义数据不误报、按可见时间原生选择、集中核对并返回原顺序、刷新后新时间、准确取用、原稿保持、应用撤销重做与保存读回。给定内容库和音频字节保持；后续资源时间变化由受控合成修改提供。

原型仅替换给定浏览器中的列表模块；最终源码任务未替换产品模块或页面结构，并实际省略Python、Git及测试根覆盖。这里核验资源说明与取用，不新增对真实视频播放、托管账号、实体设备、输入法或作者长期使用的结论。当前准确提交CI、服务器QA、部署和私人安装仍待对应阶段。
