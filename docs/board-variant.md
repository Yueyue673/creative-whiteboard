# 另起一版，保留原稿

想试另一种材料安排或写作方向时，在当前白板的“更多操作”中选“另起一版”，确认新版本名称，再选“创建并打开新版本”。新白板在同一侧的新标签中打开，原稿标签保留。点原稿标签即可回去接着写。

新白板包含创建时的内容、连线、位置、视角、表格中的材料、媒体时间标记与来源信息。两张白板之后各自编辑；媒体共用原文件，内容里已有的跳转继续指向原来的目的地。这是独立白板，不会自动把两版的修改合在一起。

创建前会等当前导入完成，确认原白板与所属范围，再取当前内容。名称为空、准备失败、准备期间取消或所属范围变化时，不创建空白板。写入失败会保留名称和原稿；若保存已成功但确认稍后才到达，关闭过的确认框不会强行打开新标签，新版本仍可从白板列表找到。若服务器已保存、但网络返回中断，“核对这次创建”会只读核对本次名称与完整内容，确认一致后打开已有版本，不再发送第二次创建。暂时未找到、读取失败或没有权限时，保留原稿并停止写入；版本已有后续变化时也不覆盖。可以返回原稿，之后再明确决定是否另起。这个确认只保留在当前确认框中，关闭或重新载入后不会自动重试。

原白板的保存、冲突和删除恢复入口沿用原方式。

原稿标签仍在本窗口打开时，返回会沿用原输入框、选区、滚动和撤销重做。关闭或重新载入过的页面按原规则读取保存内容，不保证恢复旧的浏览器编辑历史。此入口目前位于带标签的主工作台；独立旧页面继续使用原操作。

## 验证范围

1360与320宽窗口的完整合成任务已验证：命名创建、文字与图片、带格内内容的表格、音频引用与时间标记、手动尺寸与位置、连线、来源、现有跳转与扩展字段保存；新版本独立修改，返回同一个原稿输入框，原生选区、滚动及撤销重做继续可用。内容库没有被改写，也没有复制媒体文件。

另核空名称、取消、失效回调、目录准备失败、新版本写入失败、取消后的延迟确认，以及受控的账号、工作区与暂停条件。网络故障和范围输入均为隔离合成条件，真实托管账号未验证。原标签恢复与白板删除恢复任务沿受影响路径通过。

新增任务登记在原Checks流程，当前准确提交CI、公开上传、服务器核验、部署、私人安装、实体设备、输入法和作者实际使用仍待对应阶段验证。没有测量真人操作耗时或理解成本，也不表示网站和旧体验入口已经更新。

保存返回中断的本机合成对照已实际复现原入口再次点击会生成第二个编号；修复后只读找回首次保存，创建请求保持一次。另核JSON属性顺序不同、结果暂时未找到、读取失败/拒绝、已有后续变化、读取中取消、失效回调及所属范围暂停，均不自动重发创建或覆盖。故障与范围输入为受控条件，服务器实际保存在原隔离服务中。
