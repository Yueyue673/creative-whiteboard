# 先在内容库写表格，需要时再放到白板

内容库中点“写表格”，直接开始三行三列的小表格。可改列名和格子文字；标题可以不填，库中的名称沿用首个非空格子的首行；没有格子文字时，也可沿用明确改过的列名或说明。只填写标题，也能保存一份自己命名的空表模板。没有输入内容或标题时，不会因为默认列名而保存空资源。

表格沿用原工作台的三行三列起步方式。需要增减、移动行列或整理格内材料时，保存后放到白板继续编辑，再沿原入口收录。这里没有新建另一套表格格式或结构编辑器。“写便签”保留原来的一次点击、主要两个写作字段和正文焦点。

不必打开一张白板才能保存表格。先选存放位置，写完后保存到内容库；内容库列表、原件编辑、预览与“放入所选”继续用原来的路径。没有活动白板时，取用会打开原选择去处入口；取消保留原预览，明确选定后才新建或打开白板并放入副本。之后对白板副本的修改不自动覆盖库中积累的原件。

## 保存结果不确定时

在同一个新建表单里，如果保存已落盘、只是回执丢失，再次点保存会先按这次内容的编号读取结果。内容一致时直接确认已保存，不再写一次；如果它随后又被修改或移入回收站，输入留在当前表单，可以明确“另存我的编辑”，后来版本保持原样。

这项核对也沿用在同一新建表单的便签保存。它只覆盖当前打开表单的这次新建；不是跨浏览器任务队列、跨会话草稿恢复或新的同步协议。原读取失败、取消期间继续创作、账号与工作区观察和版本选择流程保留。
