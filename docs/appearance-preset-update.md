# 更新一个已经保存的外观

在“外观与操作”里调好设置后，点“我的预设”中对应一行的“更新”，就把当前外观与操作偏好存回该预设。原名称、顺序和其他预设保留；“保存当前外观”仍用于另存新名称，原有同名保护继续生效。

更新后可以点“撤销更新”恢复那条已存预设，当前正在看的外观保留。重复点相同设置的“更新”不会取消上次实际更新的撤销；若那条记录已有后续变化，旧更新或撤销会提示重新查看并保留后续记录。满24条时仍可原位更新，无需先移除再重存。预设仅保存在当前浏览器，不承诺跨窗口事务或云端同步。

给定任务比较中，调好同一设置后，原有“移除旧项、填回名称、重新保存”的三步可以变成一次明确更新。这是动作比较，没有测量真人用时。最终源码1360px/320px完整任务本机通过，核对原名称/编号/顺序、其他预设、原生撤销、重复点击、脱离窗口的旧按钮、无效颜色/移动距离、满额更新及刷新后的准确读回。后续存储变化和保存失败使用一次性浏览器资料中的受控模拟验证，不代表真实多窗口并发验收。

原外观流程和外观返回写作两项受影响任务通过；同一原稿输入框、反向选区、续写撤销重做和保存新页读回保持。新任务省略Python/Git/测试根覆盖，17项运行文件磁盘与实际服务字节一致。当前尚未公开；对应CI、服务器QA、部署、私人安装、其他短低窗口、实体触摸、输入法和作者长期使用未验。
