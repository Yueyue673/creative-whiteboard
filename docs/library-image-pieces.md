# 在取用组合内容前看图片

内容库打开一组资源后，图片块的原勾选行下方可展开“查看图片”。看清以后仍在原复选框勾选，用原来的“放入所选”取出副本；展开图片本身不选择、不创建副本，也不进入原件编辑。

画布图片沿已有图片画面显示当前裁剪和标注，不拿未裁剪的原图替代当前版本。普通便签的附带图片按原图片显示，正文摘要和其他材料继续留在原行。查找后回到这块内容时，当前预览中的展开选择保留；关闭预览结束这次临时阅读。

图片按需读取。读取失败可以重新读取，原勾选与原件保持；较多附件、标注或极端比例超出这里范围时，可先选中并放到白板查看。当前预览上限为普通便签8张图片，或画布图片200个标注、16000个点、12000字标注文字，画面宽高比0.05至20。这里只预览组合根层图片，不读取表格内全部素材，不替代原图细看与原件编辑。

原型比较了原列表中展开和单图阅读后返回。给定同名、共用媒体但裁剪标注不同的两块图片，在取用前能辨认当前画面；原列表方案保留勾选位置与原取用范围，未增加一层返回。动作与滚动分别记录，不代表真人速度。

本切片已在本机通过宽窄窗合成任务：裁剪标注画面、实际读取失败重试、过滤与键盘、范围上限、准确取用、续写撤销重做及保存新工作台读回。原组合预览和布局示意的受影响范围通过；最终图片摘要反馈仅改新入口，范围等价依据保留。对应准确提交CI尚未运行，公开上传、服务器QA、部署和私人安装均未做；实体触摸、输入法、其他浏览器和作者长期使用未验。
