# 一次挑多块，接在原段落后

展开长文，先点正在写的段落，再打开“在此处后添加”→“从内容库取用…”。只需要一块时，仍可直接点结果里的“将副本接在原段后”。

需要几块独立材料时：

1. 勾选“一次取多块”。查找便签、表格或组合中的内容，点“选这一块”；换一个查找词后，已选内容仍留在“本次取用”里。
2. 核对选中的内容和顺序。列表按选择顺序显示，可以移除某一块；上方仍显示“放在第几块后”和原段落。
3. 点“将选中的 N 块接在原段后”，一次放入副本，回原段落继续写。也可以“返回原文”或按 Escape 取消。

从同一个已存组合中挑两块时，每块仍保留自己的来源。这个入口分别取用独立块，库中原组合与连线保留；需要整组连同关系一起复用时，继续从原内容库放到白板。

取用前会重新核对全部所选原件。原件变化、移除或无法准确对应时，本批还不会放入；发生变化的选择会移出列表，需要读新预览后重新选择。其余选择保留，最终顺序以“本次取用”显示为准。读取失败可以重试，已有选择保留。取消后的迟到读取不会重新打开面板或代替后续输入。

明确回到画布后，可以一次撤销或重做本批插入。文字输入仍沿用原输入规则，结构插入后会恢复原段落的文字与选区。
