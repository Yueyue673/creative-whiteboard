# 选中资源后，直接放入所选

在内容库勾选后，计数旁显示“放入所选”。可以先“查看已选”核对，也可以直接点原取用动作；没有选择时不显示这个按钮。原右键菜单、Ctrl+Enter和拖放方式继续可用。

按钮沿用原取用处理，等待本次添加时显示“正在放入”并暂时不可重复点击。开始时的内容与目标保持：处理中继续挑选或切换标签，原请求仍放入原目标；原目标关闭则说明未添加，并保留选择。没有打开白板时使用原目标选择窗口，取消后不新建白板，所选内容保留。

给定1360px/320px原型中，原右键加菜单两次指针操作变成一次可见按钮点击。Ctrl+Enter本来就是一次快捷操作；本比较说明少开菜单、直接可见，不测量真人速度，也不把窗口宽度当实体手机体验。

最终源码宽窄完整任务本机通过：真实给定PNG响应被暂缓以保持实际解码等待，核对原生双击不重复、后续选择与受控标签切换不改原归属、关闭原目标不回退写入别处、空选择、右键选择更新入口、无白板时原生取消，以及准确取用两条材料、原稿续写撤销重做和保存新页读回。库中原件与PNG字节保持，给定入口高44px。原选择稳定与已选核对返回两项受影响任务通过；20项磁盘与实际服务源码字节一致，新任务省略Python/Git/测试根覆盖。

原取用、等待与目标归属模块未改；其中两个文件有已验的帮助/隐藏大纲差异，取用相关片段与最近公开源码逐字节相同。原关闭标签提示曾遮住任务下一步入口，保留证据后按原按钮收起提示继续，没有改原提示。当前尚未公开，对应CI、服务器QA、部署、私人安装、其他短低窗口、实体触摸、输入法和作者长期使用未验。
