# 在窄窗里边看文字资料，边接着写

展开普通文字便签并查看另一份文字资料时，窗口有足够高度会提供“同时看”：原稿在上、只读资料在下。可以直接继续写，也可点“只看资料”回到原整页查看，或“返回记录”结束这次对照。默认仍先整页查看资料，宽窗保留原来的左右对照；带文件的便签、表格和其他材料沿用原查看方式。

上下对照只调整原来的两个界面，不建立另一份原稿或新工作台。正常高度保留资料的完整标题；已经选择上下对照后再缩短窗口，会保留当前输入和退出入口，短区域只适合短句参照。新开矮窗口时不提供这个选项。真实手机键盘弹出后的布局与舒适度尚未验收。

给定原型的三轮看写任务，从进入资料到继续输入，原流程涉及11次视图动作，上下对照涉及3次。两组都使用原生输入、撤销重做和准确保存；这是给定动作比较，没有测量真人速度。

最终源码在320×900与390×660完成任务，并在任务中切换至1360px宽窗和420px矮窗：同一输入框、选区、原生续写撤销重做、资料滚动位置、原整页查看和返回动作保持；表格不启用新布局，新开的矮窗也使用原查看方式。原稿、资料、手动尺寸与后续新页读回准确。原引用返回10项检查和读取活动8种条件通过；后者包含受控等待与输入通知，不能代替真实网络或实体设备验收。

17项磁盘与实际服务运行字节一致，新任务省略Python、Git与测试根覆盖。当前是未公开的本机源码候选，对应CI、服务器QA、部署、私人安装、实体触摸、输入法和作者长期使用未验。
