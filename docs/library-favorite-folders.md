# 常用存放位置，一按选好

反复把材料收进同一个文件夹时，在原“存放位置”里找到该文件夹，点“记为常用”。以后收录材料或在库中写便签时，可以直接点显示的完整路径选好位置，不必重新输入路径或逐层进入。原来的默认位置、搜索、文件夹浏览和新建入口保留。

常用位置只存在当前浏览器，最多12个，不保存材料正文，不修改内容库，也没有新增跨设备同步。明确记住的位置会继续保留，即使这次收录后来取消；可随时点旁边的“×”移除，再用提示中的“撤销移除”恢复。移除快捷项不会移除文件夹或材料。

文件夹改名或移动后，按已有的文件夹身份继续对应。原文件夹移除后，即使另一个文件夹用了相同路径，也不会把它当成原位置。暂时不能准确记住的位置仍可从原入口正常选择。

浏览器暂时不能保存或读取常用位置时，保留已有记录、内容名称和当前选择，原位置选择继续可用。其他窗口改过记录时，本窗口会刷新；失效的快捷项不会替你选择一个同名文件夹。

## 验证范围

1360与320宽窗口的合成完整任务，先按原搜索与浏览器选择深层目录，再比较明确记住的位置。给定任务中，重复选位置从四个动作（包含输入路径）减少为一个快捷选择；这不是对真人理解或耗时的测量。新位置会明确显示，原默认位置不变。

实际收录后从原内容库取到另一张白板，核对便签、连线、来源、撤销重做与保存重开。另核移除撤销、过期回调、存储失败与重试、不可读/未来格式、改名、移除后同名重建、库中写便签的共享选择器、同源窗口变化与所属范围变化。网络/目录条件和浏览器存储故障均用隔离合成条件，原型与实际源码分开记录。

原收录核对和库编辑任务按受影响路径运行。新增任务沿原Checks流程登记；当前准确提交CI、公开上传、服务器核验、部署、私人安装、真实托管账号、实体设备、输入法和作者实际使用仍待对应阶段验证。本说明不表示网站或旧体验入口已更新。
