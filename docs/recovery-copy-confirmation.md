# 原稿被另一处移走后，保留当前草稿另存

原白板在另一处移入回收站，而这个窗口还有未保存的内容时，原标签和草稿继续保留。点提示中的“另存当前内容”，会另存一张白板，原件的删除或恢复状态保持。

如果连接中断，暂时无法确认另存结果，按钮改成“核对这次另存”。再按只读取该次结果，不会盲目新建第二份。读取失败或暂时找不到时，当前草稿保持，可以稍后再次核对；已有副本发生变化时不覆盖它，先从白板列表核对。

确认期间若继续写了新内容，较早的副本不会代替这些新文字。原标签继续保留，按钮显示“另存当前新修改”。若只是切去了另一个标签，确认完成会保留当前正在输入的位置；返回原标签后用“打开已另存副本”打开现成的那一份。

每次只处理发起另存的原窗口和标签。等待期间所属白板、账号或工作区变化时停止依赖操作；同一次未确认的请求不会跨到另一个位置继续创建。独立文档窗口也沿用同次确认。原来的移入回收站、恢复和普通另存路径保持。

## 验证范围

宽窄窗口的合成原稿验证真实落盘后受控丢失响应，再按按钮不重复创建；还核对读取失败、真实404、已变化副本、后来新写的内容、另一个标签继续输入，以及受控的账号和工作区变化。宽窗口另验独立文档路径。原稿文字、未知字段、原删除状态和本次副本按给定任务读回。

这是同一打开窗口中当前另存的保护，未新增跨窗口任务队列或正式备份恢复功能。原有生命周期任务按受影响范围另验；当前准确提交CI、服务器QA、部署、私人安装、真实托管账号、实体设备、输入法和作者实际使用仍待对应阶段。登记任务不表示网站或原体验入口已更新。
