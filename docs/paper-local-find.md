# 在展开的长文里找一句话

展开长文后，顶部的“查找”只查当前纸面已经展开的文字。输入原句中的连续文字，点结果就能到达对应输入框并选中这段原文。结果最多显示前80处，不改正文，也不查其他白板或材料。

点“返回查找前”回到刚才的输入位置；查找面板里的“返回原处”或Esc也可结束本次查找。原输入框、草稿和原生撤销保留。点击别处或继续输入会结束临时查找，正常编辑沿用原保存流程。

这是独立源码候选。隔离原型1360px与320px已走通文内定位、回原选区继续写、撤销及保存新页读回；原全局查找仍可定位原文，浏览器自带查找未作能力比较。最终源码1360px与320px完整任务、八项查找边界及两项受影响原任务均在本机通过，包含所有阅读滚动位置、取消、旧回调、换文档、字面字符及230×220的完整点击区域。准确CI、部署、私人安装和实体设备未验。
