# 编辑图片时看清当前名称

从白板打开图片编辑窗口后，标题区保留“编辑图片”，下方显示当前图片对象自己的名称。外观相同的图片、同一原图的不同试案，仍按各自对象打开；这里显示对象名称，不从共享文件名猜测。

名称只用于当前窗口的上下文，不会给画布添加常驻标签，也不改写原件、图片字节、裁剪、标注或手调尺寸。长名称最多显示两行，鼠标悬停可读全名；没有名称时沿用原来的单行“编辑图片”。取消、应用、标注与返回写作仍用原操作。

全新图文/表格合成场景对照中，原窗口两张相同画面的对象都只显示“编辑图片”；当前名称缺少可见提示。常驻画布名称方案在320px场景覆盖了相邻便签和表格，未保留。窗口内名称方案在1360px和320px可见，原图、取消/应用和回原便签续写保持。这说明给定任务中的对象辨认信息更清楚，不是测量真人速度。

本切片已通过本机合成宽窄窗对照和原图片工作区检查，涵盖缩放、裁剪、触摸模拟与保存；对应准确提交的CI、服务器QA、部署、私人安装、真实触摸/输入法与长期使用仍须分别验证。窄窗长名称末尾可能省略，实体触屏查看全名的体验未验。
