# 从表格文本开始，直接积累可编辑行列

内容库中点“写表格”，展开“从表格文本开始”。把已有表格文字贴入文本区，选择制表符或逗号分隔，并明确首行是否作为列名。核对预览后点“建成表格”，继续编辑格子，最后沿原“保存到内容库”留存。取用、选择白板和原件/副本编辑继续使用现有入口。

这里沿用原工作台的分隔文本解析。CSV 原文件仍按原文件保留，这项操作只使用你贴入的文字，不会自动读取系统剪贴板、转换已有文件或补造来源记录。普通格子里的文字粘贴保持原来的含义。

## 预览、撤回和保存

只对尚未填写格子或改过列名的新表提供建表。已经写下的格子不会被替换；标题、说明、补充和备注保留原输入节点。预览显示完整行列数量、前5行及6列，每格最多展示160个字符片段，建表和保存使用完整文字。

建表后，原文本保持可查看、选择和复制，分隔方式固定；可以继续改格子。“撤回这次建表”会接回原来的格子节点和位置，并保留文本。撤回先核对格子是否已有后续输入，有后续变化时保留它们。想更换文本时，可在没有后续格子修改的状态撤回再调整；当前表也可先保存，再另建一张。

收起文本面板、解析失败或撤回建表时，文本仍留在当前表单。尚未用于格子的非空文本会阻止误保存，包括保存核对等待期间才补入的文本；先建成格子，或者由使用者明确清空待建表文本，再保存当前格子。取消整次新建沿用原关闭表单规则。

支持最多100行正文、12列、262144个浏览器输入字符；首行作为列名时不计入正文行数。超过范围或引号未闭合时保留完整输入和原表。建表后可在末尾“加一行”继续记录；更大的表格及删除、移动行列、改列数继续使用原白板导入、编辑与收录路径。多列编辑区域可以在本地横向滚动，文字不挤成窄条。
