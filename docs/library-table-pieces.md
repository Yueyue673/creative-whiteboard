# 取用表格前先看内容

在内容库打开单张表格或一组资源，表格的原勾选行下方可展开“查看表格”。先读单元格、格内记录与素材名称，看完可“收起表格”，再用原勾选框与“放入所选”取用副本。阅读本身不选择、不创建临时副本，也不编辑库中原件。

这是一份只读内容预览：文字按字面保留，格内图片和文件以名称提示，不在这里播放或编辑。长表沿原预览区滚动，较宽的表格可横向查看；原表格的手动尺寸、行列与格内内容保持。查找后返回保留本次展开，关闭预览后结束这次临时状态。

普通表格沿用现有长文的有界文字渲染：最多约20万字符、2000个结构片段（包含表格、格子与格内内容）、16层嵌套；根表最多100列，明显不完整的行列结构会回到原取用路径。超出范围时不展示一部分冒充完整表格，原件保留，可放到白板查看。这里只扩展普通表格，原长文阅读、图片预览和取用方式继续保留。

给定宽窄原型中，两张同名表格可在取用前按实际内容辨认，并完整取用乙表后续写；单张表格资源也可读。副本身份仍按原流程生成，文字、行列、格内内容、附件和尺寸按取用范围核对。没有测量真人速度或声称这是所有现有方法的唯一选择。

本机合成流程在1360px和320px均通过，含32项保护检查；原长文、资源部分取用及图片预览三条受影响流程也已通过。本机合成检查、准确提交CI、服务器QA、部署、私人安装及实体验收分别记录。当前对应CI、公开上传与部署尚未做；实体设备、输入法、其他浏览器和长期作者体验未验。
