# 再次取用本窗口用过的资源

内容库原“内容顺序”中可选择“最近取用优先（本窗口）”。本窗口已取用过的项目在前，其他项目保留原顺序；默认仍是“原来顺序”，也可继续选择“最近保存优先”。文件夹、搜索和类型仍限定结果，不会把别处或已归档的资源带进来。

记录只在原取用流程返回新增内容编号后加入。只预览、取消或取用失败不会记成成功。它最多在当前窗口内容库中记住最近200项，不修改原件、目录、保存时间或浏览器存储；刷新或关闭窗口后清空。

排序在原列表再次打开、搜索、刷新等操作时更新。异步取用完成时保留眼前的列表与输入，避免突然重排影响选区和正在进行的查找。批量取用的项目视为同次取用，彼此保留原顺序。后续在白板撤销副本，不会抹掉“曾取用”的窗口记录。

给定240项同名旧资源的原型对照中，取用A、再用B、再回找A，原浏览需要两次“显示更多”，选择新排序一次即可显示A。这是给定浏览路径的步骤比较；记得关键词时原搜索仍可直接定位，不代表真人速度或所有查找方法。
