# 把自己的预设带到另一个浏览器

在“外观与操作”的“我的预设”下展开“预设备份与导入”，点“导出我的预设”，把已经保存的预设留成一份文件。文件包含预设名称、外观和操作偏好；当前尚未保存的调整需先存成预设。它是手动文件，不会自动同步浏览器。

在另一浏览器选择这份文件后，先查看并勾选要加入的预设，再点“加入我的预设”。已有同名项保留；导入不会改变正在使用的外观，之后可以从“我的预设”明确选择应用。可取消预览，也可撤销刚才的导入。若导入的记录后来改过，旧撤销会保留后续改动。最多保存24个；容量不足可少选几项，不会只存一部分。

给定宽窄任务中，重新设置一份完整预设涉及17项控件动作；已有文件后可展开入口、选择文件、确认加入并应用。这里比较的是给定操作，没有测量真人速度或系统文件选择器的耗时。候选在原设置页中，备份入口默认折叠，未建立另一套工作台。

1360px与320px完整任务本机通过：真实下载并在新的隔离浏览器资料中导入，已有预设编号、顺序和内容保留，取消及撤销可用，预设刷新后准确读回；返回原稿的同一输入框与反向选区后，可续写、撤销重做、保存并在新页读回。新增预览的操作区域与勾选行至少44px，窄窗无横向溢出。文件类型、损坏和大小限制、同名重复、受控容量不足、存储失败重试、后续记录变化及关闭后迟到读取均已核对。存储和文件延迟保护使用一次性浏览器资料中的受控模拟，不能代替真实多窗口事务验收。

原外观、外观返回写作与预设更新三项受影响任务通过；17项运行文件的磁盘与实际服务字节一致，新任务省略Python、Git与测试根覆盖。当前仍是未公开的本机源码候选。对应CI、服务器QA、部署、私人安装、其他短低窗口、实体触摸、输入法和作者长期使用尚未验收。
