# 在分组的空白处开始写

在足够容纳默认便签的分组空白处右键，选择“在这里写便签”。工作台在靠近该落点的位置创建一张空白便签，保留组内原材料和连线；默认便签会留在组框内，不挪动或扩大原分组。新的文字由作者输入，不复制素材内容或自动连线。

宽窗继续使用原行内编辑。窄窗使用原展开编辑，写完通过原“返回白板”回到工作台；原落点和分组仍保留。原双击改组名、普通便签新建、资料编辑与保存方式继续使用。

分组标题、控制按钮和已有内容的菜单保持原用途；正在编辑、分组过小或编号不明确时不提供这项新动作。新的便签仍采用原自动大小，文字增加或重新阅读时高度可重算；原有手动尺寸不因此改变。这不保证新卡片与附近所有材料都没有重叠，落点由作者选择。

本机1360px/320px原生流程与21项保护检查通过，原分组命名及从资料写记录两条任务通过。本机合成检查、准确提交CI、服务器QA、部署、私人安装与实体体验分别记录。当前对应CI、公开上传和部署尚未做；实体触摸、输入法、其他浏览器和长期作者体验未验。
