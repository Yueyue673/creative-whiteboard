# 在内容库表格的末尾继续记录

编辑库中的普通表格，或点“写表格”新建一张，在格子下方点“加一行”，就能接着填写一条记录。焦点进入新行第一个格子，已有格子、标题、说明、补充和备注保留原输入框。写完仍需点“保存到内容库”；加行本身不会保存，也不需要先放到临时白板再收录。

这次新增且仍为空的末行可用“撤回新增空行”移除。新增行已有文字或资料时会保留它；这项操作不删除原有行。格子文字继续使用原生撤销与重做。组合里切换到其他内容再返回，新增行和已写文字仍在。

这里支持在最多100行、12列的小表格末尾加行。已有更大表格不会被截断。需要新字段时，可以[在末尾加一列](library-table-append-column.md)。删除、移动已有行列或编排格内材料，继续沿白板编辑和收录的原路径。长文中的嵌入表格不增加这组操作。

从表格文本开始时，先核对并“建成表格”，再加行；尚未建成的文字不会被丢下。新增行保留后，原建表撤回也不会清掉它。先撤回仍为空的新增末行，可以继续沿原来的“撤回这次建表”返回。

保存沿现有目录读取和整张表格版本核对。另一处同时修改文字、行列对应或格内资料时，先对照库中版本和自己的编辑，再明确选择。已有白板副本保持原样；之后取用的新副本带上保存后的行。原文件、格内材料、已有行编号和其他未改字段保留。旧表没有行编号时保持原格式；现有编号无法准确对应或末行之外还有资料时，停止加行并保留输入，供回到白板核对。

这是独立候选源码的用法。当前提交的准确 CI、网站更新、私人安装、真实账号与实体设备体验分别记录，不能用本机合成核对代替。
