# 首页视觉

首页用 `mark.svg` 作为原创矢量标志：两张纸页表示原件与副本，蓝色回环表示再次使用。暖纸白 `#faf9f3`、墨色 `#222923`、黄绿色 `#e2ef85` 和蓝色 `#4354d6` 沿用本项目的纸页与复用意象。标志不依赖外部字体。

正文沿用 GitHub 的字体与标题层级。主要入口放在开头；纸面概念封面说清用途，接着用真实工作台画面解释具体操作。截图统一使用本机版的纸白外观，正文不叠加宣传文字，不拼造尚未实现的按钮。演示材料来自公开示例，见 [截图说明](../screenshots/README.md)。

介绍顺序参考 [Voyager](https://github.com/voyager-crew/voyager)：先说用途和入口，再给产品画面与场景，最后放安装、限制和参与方法。本项目没有使用它的标志、截图、文案、评价或使用数据。

`reuse-cover.svg`、`reuse-cover-mobile.svg` 及同名 PNG 保留为可编辑的复用流程示意。它们是说明图，不是产品界面；首页以真实案例截图展示已经实现的操作。

## 纸面主视觉与独立海报

`reuse-paper-cover.png` 是 1600 × 800 的首页封面；纸页、便签、连线与收存口袋表达“这一组，下次接着用”。它是标明用途的概念插画，不是产品截图。两幅纸面插画通过内置图片生成工具制作，现有标志保持原文件，中文、网址和命令用排版工具准确合成。

[四张独立海报与下载](../posters/README.md)采用相同纸白、墨色、黄绿和蓝色；分别用于介绍用途、展示分栏场景、解释整组复用、引导开始。生成提示词与可编辑排版见该页的维护说明。旧 SVG 流程封面继续保留，不将旧资源删除或冒充新界面。
