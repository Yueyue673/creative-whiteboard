# 用白板所选材料起一份长文

白板上已有几段摘录、图片、录音卡片和普通表格时，先选择要用的内容，再打开“选中内容的更多操作 → 用所选新建长文”。单块内容也可以从原右键菜单进入。

先看原文摘录，再用上下箭头调整这次起稿的顺序。这里的顺序由你确认，白板上的分类和位置不自动当作成片或文章顺序。同名内容会显示各自的原文片段；材料较多时分页显示，跨页移动后仍能接着调整刚才那块。

“创建长文副本”把每块材料作为可独立编辑的副本放进新长文，末尾留一段正文让你接着写。它沿用原长文编辑、文字撤销和保存方式，不替你改写或合并原话。原便签、位置和画布连线留在白板，长文副本不复制画布连线。

取消预览不创建内容。创建后尚未续写时，白板的一次撤销可移除整份新长文，重做可恢复。原“长文”按钮继续创建空白长文。

目前可选便签、图片、文件与音视频卡片，以及没有格内附件的普通表格。已有长文、分组、形状或带格内材料的表格混在所选中时，这一批会先停止，避免只搬走一部分。先取消选择不支持的内容，再重新起稿。

## 验证范围

本机隔离合成场景覆盖1360与320宽窗口：原多选和菜单、同名原文辨认、键盘排序、分页与跨页移动、取消、过期回调、复杂表格整批停止、独立副本、原连线与来源、单次创建撤销、续写的文字撤销、保存和重新读取。音频字节和原库资源保持。另运行未修改的原长文写作任务。

测试没有读取作者内容、使用系统剪贴板或更新已有体验入口。菜单和编辑器使用实际源码，未替换产品模块或页面结构；过期回调由测试保留后显式调用。账号、工作区与只读状态的保护另按源码条件记录，真实托管账号、实体设备、输入法、作者体验、当前准确提交CI、服务器核验和部署仍待对应阶段验证。登记CI任务不表示已经运行或发布。
