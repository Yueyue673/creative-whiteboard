# 带连线的组合先放在白板上

表格格子可以容纳卡片，但当前不能表示组合内部的连线。把带连线的组合拖进格子，或把这类结构化内容粘贴进去时，会保留格内原有内容，并提示“这组内容含连线，请先放到白板保留关系。”混合选择中只要有一份带连线，本批都不会写入格子，库中原件保留。

在内容库选中该组合，点击原“放入所选”，把它放到自由白板，继续带着内部连线编排。没有连线的组合、单块便签及普通文件仍可按原方式放进格子。

本机1360px原生库资源拖放，以及320px受控内部拖放/粘贴事件，共20项检查通过：连线组合和混合批次不会部分写入；无连线组合、普通文件、正常粘贴、原处续写与撤销重做保持；原白板取用保留连接，资源原件、媒体字节和保存新页读回准确。原单元格新增/文件路径任务也通过。
