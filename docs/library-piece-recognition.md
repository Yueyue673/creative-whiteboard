# 辨认组合里要编辑的内容

在内容库编辑包含多块内容的组合时，“选择要编辑的内容”仍是原来的下拉框。每项显示原顺序中的序号、类型，以及标题或已有文字的短摘录。没有标题的便签、表格也能辨认；同名内容用序号和类型区分，不需要先替每一块取名。

提示优先用已有标题，再用正文、补充或备注。普通表格还会查看前三行、每行前四格及前四个列名；长文查看前四个文中材料的现有标题、正文。提示把换行和连续空白合成空格，最多显示36个 Unicode 码点，其余用省略号表示。提示不替代完整内容，也不搜索、读取附件文件。

选中后，完整文字仍在原编辑区域。切换离开时，原草稿照常保留，该项提示也会反映刚编辑过的标题或文字。这里不会自动命名、改写正文、调整顺序或保存；写完仍需点“保存到内容库”。Esc 会保留未保存输入，明确取消才放弃。

这是独立候选源码的用法，尚未代表默认版本、网站或私人安装已更新。本机宽屏与320宽视口的合成核对包含辨认、切换、正确对象保存及原文保留，不代替真实账号、手机、读屏或作者实际创作体验。准确提交 CI 与发布另行记录。
