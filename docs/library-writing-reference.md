# 看着库中便签原件，继续写当前记录

在普通文字便签的“关联”窗口中，点“库中原件”，按名称、目录或文字摘要查找，选择需要对照的便签。宽窗沿原资料栏放在旁边；窄窗展开编辑时可以选择原来的“同时看”，上下查看与写作。点“返回记录”回到同一个输入框、选区和阅读位置。这里只读查看，不把资料写进正文，也不创建引用或临时副本。

这条入口供不含文件、图片附件和画布对象的普通文字便签写作使用；可选择组合资源根层中同类文字便签的原件。同名资源显示各自目录、内部标题与文字摘要，按准确资源和内容编号打开；作者当前便签即使来自另一份原件，也能明确查看本次选择的资料。原“来源与版本”仍按当前副本的原件绑定，库中更新与永久引用沿原流程。长文、表格、格内材料和文件资料保留原入口。

读取使用原有当前账号/工作区的内容库接口，不更换写作中的共享索引。选择后重新读取原件；已移出、改变类型或无法唯一对应时保留原稿并说明，返回后继续输入不会被迟到结果重新打开。切到库中原件后，原白板关联查询不继续下一批；已经发出的读取自然结束。

当前查询有界：目录响应最多8 MiB，最多检查12000个结构片段、收集600份候选，另有60毫秒的本地扫描时段；默认显示30项，可继续显示更多。达到上限会明确说明只列出了部分范围；搜索只在已列出的候选中进行，其他材料可从内容库查找。这里只查当前可读的组合原件，不包含历史、回收站或其他账号/工作区，不新增持久索引。

本机原型比较了直接从库预览进入、以及从原写作“关联”窗口进入。后者在1360px原位编辑与320px展开编辑中均能真实看着资料输入，保留原字段、反向选区、文字撤销与保存，不放入临时副本；前者在窄窗展开写作中缺少可达的全局侧栏入口，未保留。比较说明给定任务中的操作和上下文，未测真人速度。

正式源码的独立合成任务验证宽窄选择、原稿返回、真实输入、原生撤销重做、仅正文变化、库原件/共享索引保持和新工作台读回。保护范围包含读取失败重试、范围/结构/响应上限、重复身份、原件归档/类型变化、迟到读取、旧回调与查询范围切换。准确提交的CI尚未运行；服务器QA、部署、私人安装、实体设备/键盘/输入法及作者长期使用分别未验。浏览器任务 tests/browser-library-writing-reference.cjs 通过 LIBRARY_REFERENCE_PROOF 留独立证据，原npm任务只注册一次。
