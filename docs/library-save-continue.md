# 保存后留在当前内容继续写

编辑内容库里已有的资源或文件说明时，点“保存并继续编辑”。它先沿原保存流程核对最新版本，保存成功后保留当前输入框、文字选区和原生撤销记录，接着写就可以；不必退出，再打开资源、选择其中的内容块。原来的“保存到内容库”（文件说明中为“保存”）仍会保存后退出。

保存成功会显示“已保存，可继续编辑”；继续输入后这句提示消失。以后再保存，会以刚保存的内容核对。原生撤销若回到不同于已保存内容的状态，仍算未保存输入，Esc 会保留表单；回到已保存内容且没有其他改动时，Esc 可以退出。点“取消”会退出，最近一次保存后的未保存输入会放弃，已保存内容保留。

如果库中另有更新，且合并会改变当前表单所展示的版本，“保存并继续编辑”会保留输入并提示使用原保存按钮核对、合并后重新打开。同一处的冲突仍须自己选择版本。不会把另一个版本悄悄换进正在输入的表单。保存失败后输入仍在；再次点击会重新核对，不会自动重试。

这是已有内容的明确保存动作。新建内容与“另存我的编辑”沿原流程完成后退出。已放到白板的副本保持原样。

本功能已接入独立候选源码，尚未合入默认版本，网站与私人安装未更新。本机合成验收覆盖宽窗口和320像素窄窗口的重复保存、原生撤销与Esc、表格空行空列的继续编辑、文件说明、后来输入、受控保存失败/响应丢失及版本与所属位置核对；没有验证真实账号、手机实体设备、输入法或读屏体验。准确提交CI和服务器QA另行记录。
