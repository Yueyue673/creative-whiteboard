# 先核对已选资源，再取用

内容库选中资源后，点计数旁的“查看已选”，可以把不同搜索中选中的内容集中看清，再用原勾选框排除不需要的项目。预览和原取用方式继续可用；“返回原列表”回到原搜索、类型、顺序、分页和阅读位置。

这个临时视图显示全部已选资源，暂时不按原搜索、类型和位置限制列表。原条件保留并暂时不可更改，返回后继续使用。清空选择时仍可返回；主动进入目录则按原目录导航规则结束核对、清空当前选择。核对不会改资源原件或创建副本，取用仍走原目标和保存路径。

给定240项资源、跨三次搜索选中3项的原型对照中，原来清空搜索、两次显示更多才能让3项共同出现在240项列表中；新入口一次只显示这3项。原来逐项重新搜索名称也可查看，此处比较的是集中核对的动作与列表，不是真人用时测量。
