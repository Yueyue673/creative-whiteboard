# 把后来补写的内容另存为独立资源

这是独立候选源码中的功能，尚未代表网站或私人安装已经更新。

在已有资源里[添加便签](library-append-note.md)并保存后，可以打开预览，勾选新便签，或将它与原来的表格、便签一起勾选。在“所选内容”中点“另存所选”，直接留下这次需要的内容，无需先放到临时白板再收录。

如果所选包含后来在库里补写的内容，保存窗口会说明：这份另存是独立资源，保留原组合收录时的白板供参考，不用原白板整体替换。填好名称和位置后保存；原资源与原白板保持原样。所选的内容、其中的连线和文件引用一同保留。

新资源预览的“原件”菜单中，“查看原组合收录时的白板”打开那张白板的当前内容，随后可以返回。这个入口提供原组合的上下文，不表示后来补写的便签曾在那张白板上，也不自动更新这份独立资源。再次另存其中一部分时，仍保留这份来源参考。

只选择能精确对应原白板的内容时，继续保留原来的来源更新与对照入口。来源记录本身无效时，保留原保护提示。

“返回选择”保留原勾选和预览。保存冲突或结果尚未确认时，名称仍在原窗口，可以明确重试；已确认保存的同一份另存不会重复添加。
