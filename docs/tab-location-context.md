# 同名白板标签的位置提示

同时打开同名白板时，标签第一行保留白板名，第二行显示已有文件夹位置。例如两张“观察”分别位于“项目甲 › 原话”和“项目乙 › 原话”，可以直接按位置切回原标签，少打开一次白板列表。

只有打开的名称冲突时才显示位置，标签栏增加 8px；名称不同后恢复原高度。分栏、关闭和撤销关闭沿用原操作，已挂载的写作框保留。没有重命名白板、复制内容或创建新的白板。

位置来自已有目录元数据。恢复标签时按需读取目录；原打开列表、白板列表和成功的文件夹操作会刷新提示。读取失败显示“位置暂时无法读取”，可沿原打开列表重试。长路径会省略，完整位置保留在标签提示及可访问名称中。同名且同文件夹仍可能相同，需要沿原列表查看内容；其他窗口的目录变化需原列表刷新后可见。
