# 修改原件后，接着用原来的选择

这是独立候选源码中的功能，尚未代表网站或私人安装已经更新。

在资源预览中勾选内容，再从“原件”进入“编辑原件”。点“取消”会放弃这次未保存的编辑，回到预览；点“保存到内容库”会保存后回到预览。仍然有效的原勾选、查找文字和已展开的阅读区域会保留，不必重新打开资源、逐块重选。

返回时按当前已读取的库中内容重建预览；保存成功后显示刚确认保存的版本。已经移除或编号不再唯一的内容不会恢复勾选，新添加的便签也不会自动勾选。放入目标沿用当前所属页面的原选择，不自动切换到其他白板。

“保存并继续编辑”及 Ctrl＋S / ⌘S 仍留在原输入框。没有未保存改动时，Esc 也可以回到预览；还有改动时，Esc 继续保留输入，需明确点“取消”才放弃。直接在列表按 F2 编辑，仍按原方式保存或退出。

保存尚在等待时点“取消”，按原方式退出，不晚到打开旧预览。账号、工作区、权限或所属页面变化后，停止返回；后续新开的编辑窗口也不会被先前的操作替换。

回到预览后，可以继续调整勾选，[另存所选](library-mixed-subset-source.md)，或把所选内容放到白板上。原白板与已有副本保持各自的内容。
