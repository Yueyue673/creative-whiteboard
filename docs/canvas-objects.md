# 绘图、图片与长文

这组功能已接入原工作台，并完成网站与桌面兼容更新；源码在开发分支，尚未合并到默认分支。各入口的实际范围见[版本状态](status.md)。

## 从内容开始

空白白板可以选择「画图」或「写长文」。有内容时，底部的「形状 / 画笔」可添加矩形、椭圆、箭头、线条、画笔和文字。窄窗口通过原创作工具菜单进入绘图或长文，不把桌面上的所有按钮挤在一排。

单击选中对象，拖动移动。表格拖角点时，文字、行高和图片跟着整体等比变化；拖边上的控制点调整宽度或高度，原文字大小保持。便签仍默认适应内容，也保留手动调整尺寸。

## 表格颜色与布局

选中表格后，点外部工具栏的颜色圆点打开「表格颜色」。预设和自定义颜色直接显示在表格上，深色配清晰文字，格内便签保留自己的颜色。原工作台灰仍跟随当前界面主题。

标题与格子使用原表格范围；角点整体缩放时，内容跟随外框，不再额外收缩。手调列宽、图片原件和文字保持；「更多」里的按内容调整高度仍可使用，颜色与文字沿用原来的撤销重做。

## 图片不用套进便签

新插入的纯图片直接显示为无边框对象，保留原图比例。选中后可以移动或拖角点调整大小，双击进入「裁剪与标注」，也可以点击对象旁的同名操作。内容原本带有说明时，保留图片与说明的可编辑卡片，不为了去掉外框而藏起文字；已有内容也不会自动转换。

编辑区以图片为主，下方「− / ＋」调整显示大小，「适合窗口」回到整图；也可用滚轮围绕指向的位置缩放。选择「移动」后拖动图片查看细节，触摸可用双指缩放。裁剪范围的四个角可直接拖动；切到其他工具时会隐藏裁剪框。缩放和平移不修改白板位置、原图尺寸或保存历史。

裁剪、画笔、方框、圆圈、箭头和文字标注都记录在当前对象中，不改动内容库里的原图。取消不应用草稿；应用后可用白板撤销，编辑中也有撤销、重做和「恢复原图」。恢复操作本身可以撤销。标注有数量上限，达到上限会保留现有内容并提示。

再次打开带标注的图片时，默认进入「选择」。点已有标注可拖动位置；文字和颜色栏修改选中的原对象，「删除」只移除这一条，撤销可找回。新图片仍从裁剪开始。图片编辑里的撤销与重做处理当前草稿，取消不应用；应用后也能在白板一次撤销。选中而未修改时不会新增保存或历史。

图形可以选择填色、线宽和手绘线条。文字与图形标签复用原双链处理，放进表格的图像、裁剪和标注也沿用同一显示内容。

## 写正文与移动段落

点长文正文直接落下光标，点空白纸面选中整篇长文。段落移动手柄留在文字左边，正文开头不会被手柄盖住；用原手柄可以拖动排序，也可以选择「移到」。文字编辑和段落编排分别沿用原来的撤销重做，保存后仍能接着写。

## 分栏和小窗口接着读

原先只看着一块资料时，打开分栏或缩小窗口，原标题入口会保持可见；空间足够时留在原位。点原内容旁的阅读入口可以展开查看，返回后继续原来的写作。不会自动缩小图片或长文，也不改手调尺寸。

多块内容、主动移开的空白或裁切，以及已明确选中的对象，继续沿用原来的浏览方式。这是当前窗口的阅读位置保持，不新增跨设备视角同步。

## 从资料接着写长文

先放入资料，再点「长文」；窄屏在创作工具的更多菜单中选「写长文」。文档会寻找附近空位，再直接打开原长文编辑器。返回白板后，原资料留在原位，文档的阅读起点和标题更容易看见。正文、便签和表格仍可连续编辑，创建长文也可以一次撤销、重做。

只有新文档的自动落点会调整，原有内容、手调尺寸、视角和分组不变；你仍可拖动重新摆放。附近没有合适位置或分组已满时，保留原放置位置，不把文档送出分组或自动重排旧内容。

## 误关标签后继续修改

图片或图形改到一半，误关了白板标签，点关闭提示中的「撤销关闭」，可以接回待应用的修改、图片草稿的撤销重做与原输入选区。切换标签再返回也会回到原输入位置。接回后仍可应用或取消；长文中的正文、便签和表格会返回对应输入框与选区。

关闭提示沿用原来的20秒期限，仅保留这一份临时关闭上下文。普通重新打开、刷新或退出网页不恢复未应用草稿。保存版本或权限变化时，不接回旧草稿覆盖新内容。图片原件、其他标注、手动尺寸和原始双链目标保留；浏览器原生文字撤销栈不承诺跨关闭页面保留，恢复后新输入的原生撤销仍可正常使用。

## 长文可以包含可编辑内容

「写长文」进入原来的展开编辑视图。标题下可以连续写正文，也可以插入便签和表格。文中的表格可以直接输入、增加行列，无需先取出到白板。正文、便签和表格保留各自的内容身份，使用同一保存、引用和撤销机制。

编辑时的「字体 / 颜色」可调整文档字样，不必离开当前写作。字体名称使用当前设备已安装的字体；其他设备没有该字体时会使用替代字体，不会自动上传字体文件。

返回白板后仍是一份文档；重新打开继续编辑。这里的“长文”说明编辑方式，不表示支持所有 Word 文件功能。

使用顶部搜索输入正文关键词，可以找到长文及文中便签、表格里的文字；点结果直接展开并选中实际匹配的原文。内容库中的文档也可按正文查找。等待保存确认时，当前白板以你正在写的内容为准。图片上的新增标注文字暂未纳入检索。

## 验收边界

开发检查使用独立合成内容，覆盖宽屏、320/390 像素窗口、浏览器触控输入、保存重开和原图字节核对。浏览器触控仿真不能替代实体手机、平板、输入法和长期使用验收。

新对象的拖动预览不改写待保存数据，松手后才形成一次可撤销操作。两指接管和浏览器取消会移除未完成的预览。本次准确源码检查、独立托管任务及既有发布保护均已完成；这些验收不代表所有设备或使用情境。
