# 把做过的内容，用在下一次

白板用于当前的编排，内容库用来留下以后还会用到的部分。可以先做，再决定什么值得收存。

[返回首页](../README.md) · [完整使用说明](usage.md)

## 1. 把选中的内容存成资源

在白板上多选要留下的便签、表格或其他内容，点底部的「保存到库」，或按 **Ctrl＋Shift＋L**。填写名称，选择存放位置，点「收进内容库」。

可以只留一块，也可以留一整组。组合会保存选中内容之间的内部连线；原白板上的内容保留。

![原工作台：示例白板的4块内容与3条内部连线已保存为内容库中的“观察与分镜”组合。](screenshots/reuse-library.png)

## 2. 在另一张白板继续用

从标签栏的「＋」打开或新建另一张白板。展开左侧「内容库」，找到刚保存的资源，拖到白板上；也可以选中资源，按 **Ctrl＋Enter** 整体放入当前白板。

得到的是独立副本。你可以重新摆放、修改文字和表格、连接新的内容。组合也可以先双击预览，只挑其中几块来用。

![原工作台：内容库原件保留，完整组合已取到“下一次创作”白板。](screenshots/reuse-new-board.png)

## 3. 需要时，再与原件对照

在副本上右键，选择「来源与版本…」。可以定位库中原件、查看库中更新，或用当前内容更新原件。

更新前会展示差异，由你选择方向和要更新的字段。白板上的位置与尺寸保留，其他副本不会跟着自动改变。不需要合回去时，就让这份副本继续独立使用。

![原工作台的来源与版本对话框，说明当前内容是独立副本，并提供定位、另存和比较更新的入口。](screenshots/reuse-source.png)

## 内容留下，修改仍由你决定

- 收进库不移走原白板内容；取出使用不消耗库中原件。
- 便签和表格以内容副本复用；媒体继续引用原文件。修改分类不会搬动硬盘上的文件。
- 白板上的删除与更新可以用 **Ctrl＋Z** 撤销。库中原件的更新在内容库撤销。
- 备份时保留 `data/`，以及引用在其他目录的原文件。历史记录不能代替独立备份。
