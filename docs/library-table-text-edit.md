# 在内容库直接修改表格文字

内容库中选中包含普通表格的资源，按 F2 或选择编辑原件。用“选择要编辑的内容”切到表格后，可直接修改现有列名和格子文字，再“保存到内容库”。之后沿原有“放入所选”入口复用，已经放到白板上的副本保持原来的内容。

格内便签、媒体文件引用、图片和其他材料随原表格保留。这里可修改现有文字，并在末尾“加一行”继续记录；只撤回这次新增且仍为空的末行。删除、移动行列、改列数或调整格内资料，仍在白板编辑后收录。组合里的便签和表格可以在同一表单切换编辑。未修改的旧值、缺失格子和可选数据保持原样。

## 另一处也改过时

保存沿原流程先读取内容库最新版本。若表格文字、行列对应或格内资料发生了并行改动，输入留在表单中，先对照“库中版本”和“我的编辑”。对照展示实际行列、完整格子文字及格内资料摘要；嵌套材料只显示摘要，文件内容不在这里展开。选择会保留该版本的整张表格文字、行列对应和格内资料，再点保存。后来又有更新时，旧选择会失效，需要重新核对。

表格以现有 columns、rows、rowIds、columnIds、cellItems、cellImages 为一项版本选择，防止文字与另一版附件错配；独立的说明、尺寸和其他未修改字段按原编辑规则保留最新值。表格已移除或改为长文时，停止旧表格写入，可沿原“另存我的编辑”保留完整草稿。读取或保存失败时保留输入，由使用者明确重试；读取核对期间继续输入的文字也会加入最终保存。

观察到的账号、工作区或编辑权限变化，会在新表格提交前停止旧操作。请求已经提交并成功、只是回执稍后返回时，按真实结果说明已保存并停止后续定位。沿用现有目录保存协议，没有新增服务端入口、永久表格格式、后台自动重发或同步协议。
