# 给已有资源补充便签

这是独立候选源码中的功能，尚未代表网站或私人安装已更新。

在内容库选中已有资源，按 F2，或从预览中的“原件”进入“编辑原件”。点“添加便签”，光标会进入新增便签的正文。它放在同一资源的末尾，沿用当前的新便签颜色；原来的内容、表格、附带文件、内部连线和来源记录保留。

通过“选择要编辑的内容”可在原内容与新增便签间切换。保存后仍是原来那份资源；已经放到白板上的副本保持原样，以后再取用时会包含新增便签。

“撤回新增空白便签”只作用于本次新增、尚未保存、当前选中且仍为空的末尾便签。写入文字、补充或备注后不能用它撤回；已经保存的便签也不会被这个按钮移除。Esc 会保留尚未保存的追加，明确点“取消”才放弃整份未保存编辑。

“保存并继续编辑”留在当前输入框；原保存按钮保存后退出。另一处有新内容时，继续编辑保存会先保留当前输入，提示用原保存按钮核对并合并后重新打开。不同的追加会一起保留。原件已移出库，或新增内容无法安全合并时，可以“另存我的编辑”，保留独立版本。

从原白板更新整份组合仍走原来的差异确认，请核对后再决定替换。
