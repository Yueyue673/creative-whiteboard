# Esc 保留还在编辑的内容

在内容库写便签、写表格、编辑原件或文件说明时，有改动的窗口不会因 Esc 直接关闭。输入、原来的文字框、选区和文字撤销仍保留；窗口里会说明如何退出。未改动的表单照常用 Esc 关闭，文字撤销回到打开时的内容后，也可以照常关闭。

继续写完后沿原按钮保存；若明确不要这次编辑，点“取消”退出。这里只保护 Esc 误关，不自动保存，也不把草稿另外写入浏览器存储。点“取消”、关闭整个窗口或刷新页面，仍须自行确认尚未保存的内容。

表格中的新增行、尚未建成格子的表格文本、组合中其他内容的编辑，以及文件说明，都属于当前输入。只切换查看组合内容、只调整空白建表面板的分隔方式，不会当作写下了内容。既有原件、白板副本和原文件保持原来的保存关系。

保存失败时，原失败原因继续显示，Esc 也不会让输入消失；可以保留窗口后明确重试。正在核对保存时，原保存操作继续按实际结果完成。明确点“取消”结束等待准备时，仍沿原有保护停止后来的写入。

这项判断接在原来的 Esc 关闭顺序里，其他预览和格式面板保留自己的关闭方式；编辑窗口结束后，本次判断会清除。它不会新建确认弹窗或叠加按键监听。

这是独立候选源码的用法。准确提交 CI、网站更新、私人安装、真实账号、输入法、读屏及实体设备体验仍须分别验证；本机合成任务不代替这些阶段。
