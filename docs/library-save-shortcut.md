# 在当前内容库表单中，按键保存后继续写

编辑内容库已有资源或文件说明时，在表单内按 Ctrl+S；使用 Command 键的环境对应 ⌘S。它执行原来的“保存并继续编辑”：核对、保存后仍留在当前输入框，选区、滚动位置和原生撤销保留。按钮的悬停说明也显示这个按键。原按钮与保存退出方式继续可用。

保存正在核对时，再按一次不会重复提交；核对期间后来输入的文字仍纳入本次保存。保存失败后保留输入，可以明确再次按键重试。版本冲突仍须自己选择；按键不会跳过核对。

这个按键只属于当前已有内容的编辑表单。新建内容、普通预览和其他窗口保留原按键行为。Shift、Alt 或同时带两个主修饰键的组合不会触发它，组合输入期间也不会触发。长按产生的重复事件只被接住，不重复保存。普通 s 和文字撤销保持原生编辑。

本功能已接入独立候选源码，尚未合入默认版本，网站与私人安装未更新。本机合成验收覆盖 Chromium 中宽窗口与320像素窄窗口的真实 Ctrl+S、重复保存、表格和文件说明、受控失败/等待/版本选择、取消后旧表单隔离及其他窗口；组合输入边界用受控事件核对，未验证真实输入法、Mac 实机、读屏或手机实体设备。真实浏览器的“网页另存为”窗口并未据此验收；准确提交CI和服务器QA另记。
