# 写长文时，回看便签的库中原件

长文里已经取用过内容库的文字便签时，该块下方会出现“查看库中原件”。点它核对原文，再返回刚才那块继续写，省去把材料取出到白板再找来源的步骤。键盘也可移到按钮后按回车。

宽窗口沿原资料查看器并排显示；窄窗口先读原件，再用顶部“返回记录”回到原文。刚才写的文字、选区和滚动位置继续保留，原件只读，不会把你的改编推回库中。

入口使用便签已经记录的准确库来源，改过标题或遇到同名资源也按原编号对应。没有来源记录的便签不猜原件，不新增自动关联或同步。文件、媒体和没有准确来源的内容仍沿用原内容库入口。

库中原件暂时打不开、已移走、编号不能唯一对应或类型发生变化时，会保留原稿并给出说明。读取中返回后继续写，迟到的结果不会重新打开资料或抢走当前输入。

## 验证范围

1360和320宽窗口的本机隔离合成流程覆盖：准确同名资源、只读原文、原稿与撤销记录、返回原字段与文字选区、滚动位置、键盘打开、文字撤销和重做、保存重开。受控重复资源编号、重复原件编号、原件缺失或改类型、读取失败、延迟取消及来源记录变化，均核对不串到其他材料、不修改原件。

另运行未修改的原长文任务和原库中资料对照任务。源代码与页面结构未被测试替换，受控网络和来源记录条件单独记录；早期原型采用临时模块与界面扩展，原型结果与实际源码结果分开保存。
