# 在原播放器选择速度

展开音频或视频的播放控件，在音量下方的“速度”中选择0.5、0.75、1、1.25、1.5或2倍。默认仍是1倍原速；原播放器、播放位置及暂停状态保持，不必另开文件。也可用键盘进入“播放速度”选择框。

速度沿已有的个人阅读偏好保留在当前浏览器，与正文、标记和文件分开。同一文件在不同内容块中的引用仍各自对应；没有新增全局默认速度或跨设备同步。若原偏好记住了选项之外的有效速度，会准确显示当前值，不把它自动改成某个预设。重新打开播放控件或在同一浏览器重新载入，会显示原阅读流程恢复的速度。

改变速度不会替换标记的名称、备注或文字输入框，文字撤销与选区继续保留。原来的“播放到下个标记”按媒体时间停止，也适用于所选速度；改回“1×（原速）”即可正常回看。已关闭控件留下的旧选择不会改动后来播放器。

这是独立候选源码的用法，尚未代表默认版本、网站或私人安装已更新。本机核对使用生成的静音WAV与WebM，覆盖宽屏与320宽窗口、鼠标与键盘选择、非预设偏好、同文件独立引用、重新载入和标记停点。没有实际听音，也没有验证真实账号、手机、实体设备、读屏、输入法或作者使用体验。准确提交CI、服务器QA与发布另行记录。
