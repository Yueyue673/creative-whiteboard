# 记住常用的白板组合

把写作白板和资料白板搭成对照后，在“更多操作 → 白板组合”里命名并记住。以后选这个名称，就能一起回到这两张白板、原来的分栏比例和写作一侧；已经关闭的白板沿用原入口重新打开。没有分栏时，也可记住当前单张白板。

组合记住当前显示的白板，不把其他后台标签纳入组合。打开组合会还原分栏，其他标签与原有输入继续保留；仍打开的编辑页沿用原来的页面、选区与滚动位置。已经关闭的页面重新读取其保存内容，不承诺恢复已关闭编辑器的光标或撤销记录。

原来的标签切换、拖动分栏和会话恢复保留。组合的用途是记住几套会反复取回的搭配，尤其是其中的标签已经关掉时；切换两张仍开着的简单白板，原标签就很直接。

组合只存在当前浏览器偏好中，最多12组。记录包含名称、白板编号、分栏与焦点设置，不保存白板正文或替代内容备份。托管工作台沿用原有账号和工作区的浏览器偏好隔离；浏览器偏好没有新增跨设备同步。

移除组合只移除这条浏览器记录，可在提示中撤销，白板内容保留。保存偏好失败会留下刚填的名称；已有记录暂时无法读取时保留原字节。读取期间取消、组合被其他窗口移除，或其中一张白板不可用，都会停止打开，不先切换一半。

## 验证范围

1360和320宽窗口的合成流程覆盖：命名、两套对照往返、已关闭组合重开、原页面与文字选区、分栏比例、其他标签、保存重开、浏览器记忆、移除撤销、同名保护、偏好失败重试、不可读偏好、失效白板、读取取消与失败重试、同源窗口记录变化、暂停范围和过期回调。配套复用未改动的原菜单活动与标签恢复任务，按实际运行结果记录。

偏好写入失败、读取延迟/失败与暂停范围是受控条件。原托管隔离桥接代码保持；真实托管账号和实体设备没有在本轮运行。新增任务沿原 Checks 流程登记，当前准确提交的 CI、服务器核验、部署、私人安装、跨浏览器、输入法和作者实际体验仍待对应阶段验证。本说明不表示网站或旧体验入口已更新。
