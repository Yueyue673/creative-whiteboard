# 把时间标记取成可复用材料

在白板音频或视频的“时间标记”里选中一条，点“取出标记副本到白板”。媒体卡右侧会新增一块独立材料：标题和内容分别保留这条标记的名称与备注，仍引用同一个媒体文件，并把所选时间设为重播起点。

原媒体、原标记和正在播放的位置保持。原输入框与选区也保留，可继续记备注；副本与原标记之后分别修改。时间输入无效时，先修正时间再取出。撤销可移除这次新增的副本，之后的文字修改沿原撤销顺序处理。

选中新材料后，沿用“收进内容库”。以后从内容库放回白板，仍带着原备注和回看时间，也沿用原有的库中原件入口。表格单元格里的独立媒体内容同样可以取出，副本放到表格右侧，原单元格保持。

这是带时间标记的媒体引用副本，未裁切文件，也没有设定片段结束时间。动作不重新上传媒体，不自动同步原标记与副本。只读资料里的标记继续用于阅读，不提供该写入入口。
