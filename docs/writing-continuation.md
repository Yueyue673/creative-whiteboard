# 在新窗口接着写

以下说明对应开发分支候选；已发布版本见[版本状态](status.md)。

重新打开已保存的白板时，想继续写的便签可能在屏幕之外。工作台会从少量现有历史中核对：如果能确定只有一条既有便签改过文字，就显示「接着写」和它现在的标题。

点一下，进入这条原便签的展开编辑。返回白板后，「返回视角」能回到刚打开时的位置；内容、手动尺寸和连线保留。也可以关闭入口，继续做自己的事。打开白板时不会自动跳转、移动内容或改变选择。

没有入口时，仍可用「全览」找到原便签。历史不足、同时改过多块内容、版本已经变化，或历史太大时，工作台会放弃推断，不猜测要接续哪一条。本机历史会合并短时间内的操作，因此不一定能提供这个入口。

窄而矮的窗口里，接续和返回留在视图工具旁；放大、缩小和全览可从比例按钮（例如「100%⌄」）打开。窗口变宽后，原来的直接视图按钮会恢复。

历史只用于找到当前便签，不会恢复旧文字，也不会把位置写入创作内容。这不是跨设备的光标同步；表格和媒体暂不提供这类续写入口。
