# 收进库之前，核对这次选中的内容

多选后点“保存到库”，可以在原来的命名窗口展开“查看这次收录的内容”，核对各块标题、部分文字、图片名称、表格摘要和内部连线数量。窗口外或未选中的内容不会加入这份摘要；完整内容仍按原收录流程保存。

这项核对可选，默认收起。可以直接填写名称、位置并收存；单块内容保持原来的简洁窗口。展开、滚动或取消核对都不会改变原白板、选择或原文。

当前为独立源码候选。隔离原型宽窄完整任务已走通收录、在另一张白板取用、继续写、撤销和保存重开。源码1360px与320px完整任务及原收录任务本机通过：准确收录快照、取消、直接收存、单块窗口、内部连线、原生撤销、独立续写与保存新页读回已核对；默认收起时不生成摘要列表，文字标记按字面显示。准确CI、部署、私人安装和实体设备未验。
