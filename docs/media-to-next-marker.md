# 从选中标记，播放到下个标记

打开媒体的“时间标记”，选择要开始的位置，再点“播放到下个标记”。它从选中时间播放，到下一条更晚的标记暂停。两条标记时间相同，不会把它们当成零长度片段；后面没有更晚的标记时，不显示这个动作。

这适合反复核对两个已有标记之间的内容，不必每次另外点播放、盯着进度手动停下。标记仍是原来的时间点，不生成片段结束时间，不循环、不裁切，也不改变“下次从这里开始”的原重播设置。

手动暂停会退出这次限定播放，随后原“播放”照常继续。用进度条换位置、选择另一标记或按原“重播”，也会回到原播放器方式。只收起播放控件时，这次停点仍生效，可以继续写旁边的内容。正在使用的标记或播放对象变化时，这次播放暂停；原标记备注、输入框与文字撤销保留。

暂停由播放器进度事件处理，不能代替精确裁切或录制。新动作只在时长已知、下一标记位于媒体范围内时可用；无效的待改时间须先修正，不会偷偷按旧时间播放。读回内容和保存仍沿原流程，不新增区间数据或后台任务。

这是独立候选源码的用法，尚未代表网站、默认版本或私人安装已更新。本机使用合成静音WAV、浏览器生成的WebM和给定标记核对宽屏与320宽窗口。WebM经真实video元素解码，核对了下一标记暂停、手动暂停续播、键盘换进度、收起控件及原文保存；没有读取作者视频。没有实际听音，也没有验证手机、实体设备、真实账号或作者使用体验。准确提交CI、服务器QA和发布另行记录。
