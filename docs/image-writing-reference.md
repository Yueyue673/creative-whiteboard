# 看着单张图片资料继续写

在普通文字便签中打开已有图片关联，窄窗展开编辑时可点“同时看”，上方继续写，下方保留资料图。图会按资料区域缩小，保持完整比例；需要细看时点图打开原查看器，关闭后回到原记录。也可以用“只看资料”恢复原整页阅读，“返回记录”结束对照。

此选项只扩展到单张已载入图片的普通资料便签，且不含正文、补充、备注、标签、音视频或画布标注对象。混合材料继续用原完整资料方式，避免隐藏材料中的文字。资料名称仍在选择框中，重复的大标题仅在此图片适应区域收起。宽窗沿原并排布局；进入时高度不足600px仍使用原资料方式。

不创建副本、引用或新资源，不改原图、原件和作者文字。是否添加图片关联、怎样写观察仍由作者决定。原型中给定三轮看图续写任务由12次视图切换降为4次，不代表真人速度；左右压缩方案在320px挤压图片和操作区，未保留。

本切片已在本机通过合成关系图的宽窄模式、原图查看、真实字段输入、撤销重做、适用范围及保存新工作台读回检查。对应准确提交CI尚未运行，公开上传、服务器QA、部署和私人安装均未做；实体手机、输入法、其他浏览器和长期体验未验。
